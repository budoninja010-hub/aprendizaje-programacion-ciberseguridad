# Ciberseguridad ética

Ruta de aprendizaje progresiva orientada a fundamentos, defensa y prácticas autorizadas.

## Organización prevista

- `fundamentos/`: conceptos de seguridad, amenazas, autenticación y buenas prácticas.
- `blue-team/`: defensa, registros, hardening y análisis básico.
- `web-security/`: seguridad web en entornos de práctica autorizados.
- `laboratorios-autorizados/`: CTF, máquinas propias y laboratorios con permiso explícito.

## Regla esencial

Todas las prácticas deben realizarse únicamente en sistemas propios, CTF, laboratorios o entornos donde exista autorización explícita.
