Concepto 1: Python y su Intérprete
1. Qué es
Python es un lenguaje de programación de propósito general, diseñado para ser fácil de leer y escribir. Su intérprete ejecuta el programa. En CPython, al ejecutar un archivo .py, primero se analiza su sintaxis y se compila a instrucciones internas (bytecode); después se ejecutan. Un error de sintaxis en ese archivo puede impedir que se ejecute incluso su primera instrucción. En la consola interactiva se procesan entradas o bloques, no necesariamente un archivo completo.
2. Para qué sirve
Puedes usar Python para crear desde aplicaciones web y juegos sencillos, hasta automatización de tareas aburridas, análisis de datos e inteligencia artificial.
3. Sintaxis (Concepto general)
Python se destaca por no usar llaves {} para agrupar código, sino "indentación" (espacios al inicio de la línea).
4. Ejemplo básico
Un script típico de Python se guarda en un archivo con terminación .py.
# Esto es un comentario
print("¡Hola, mundo!")
5. Explicación línea por línea
La línea 1 inicia con #, lo que le indica a Python que la ignore. Es una nota para humanos.
La línea 2 llama a una acción llamada print para mostrar texto en pantalla.
6. Ejemplo práctico
Imagina que quieres que tu computadora te salude automáticamente cada vez que la enciendes. Escribirías un script en Python usando comandos básicos como el de arriba y lo configurarías para ejecutarse al inicio.
7. Errores frecuentes
ERROR FRECUENTE: Intentar ejecutar Python sin comprobar su instalación. Algunos sistemas ya lo incluyen; verifica la versión antes de instalar otro intérprete.
ERROR FRECUENTE: Escribir comandos en mayúsculas: Python diferencia entre mayúsculas y minúsculas. Print no es lo mismo que print.

PARTE II — Fundamentos

En esta segunda parte, aprenderás las piezas fundamentales de cualquier programa en Python: cómo guardar información, cómo interactuar con el usuario y cómo manejar diferentes tipos de datos.
1. La función print() y Comentarios
Qué es y para qué sirve
print() es una instrucción (función) que envía información a la pantalla. Los comentarios son notas en el código que Python ignora, útiles para explicar qué hace el código.
Sintaxis
Para imprimir, escribimos print(contenido). Para comentar, usamos el símbolo #.
Ejemplo básico
CÓDIGO:
# Este programa saluda y muestra un número
print("Hola, explorador")
print(2026)
print("Año:", 2026)
Explicación línea por línea
- "# Este programa...": Es un comentario. Python lo ignora. Sirve para que otros programadores (o tú en el futuro) entiendan el propósito del código.
- 'print("Hola, explorador")': Imprime el texto literal. Lleva comillas porque es una cadena de texto (string).
- 'print(2026)': Imprime un número. No lleva comillas porque los números puros se escriben directamente.
- 'print("Año:", 2026)': Imprime varias expresiones separadas por comas. Python automáticamente añade un espacio entre ellas.
Diferencia entre escribir texto y usar una variable
Si escribes print("mensaje"), imprimirás la palabra literal "mensaje". Si escribes print(mensaje) (sin comillas), Python buscará una variable llamada mensaje y mostrará su contenido.
Errores frecuentes
- ERROR FRECUENTE: Escribir Print() con P mayúscula. Python distingue mayúsculas de minúsculas.
- ERROR FRECUENTE: Olvidar las comillas en el texto: print(Hola) causará un NameError porque pensará que 'Hola' es una variable que no existe.
Buena práctica
BUENA PRÁCTICA: Usa comentarios para explicar el "por qué" de una decisión compleja, no el "qué" de algo obvio. Abusar de comentarios (ej. print(5) # imprime 5) ensucia el código.

2. Variables
Qué son y para qué sirven
Una variable es un nombre asociado a un objeto, como una etiqueta que permite encontrar un dato. Asignar otro valor cambia esa asociación; no modifica necesariamente el objeto anterior.
Sintaxis de asignación
CÓDIGO:
nombre_variable = valor
Ejemplo básico y Reasignación
CÓDIGO:
jugador = "Mario"
vidas = 3
print(jugador)
# Reasignación
vidas = 2
print(vidas)
Explicación línea por línea
- jugador = "Mario": jugador es el nombre; = lo asocia con el objeto de texto "Mario".
- 'vidas = 3': Crea una variable "vidas" y le asigna el número entero 3.
- 'print(jugador)': Muestra el contenido de la variable (Mario).
- vidas = 2: El nombre vidas pasa a referirse al entero 2. Esto no significa que el objeto 3 se destruya: puede seguir existiendo y tener otras referencias.
Nombres válidos e inválidos
- Válidos: edad, nombre_completo, nivel1. Se recomienda usar snake_case (palabras en minúsculas separadas por guiones bajos) para variables en Python.
- Inválidos: 1nivel (no puede empezar con número), mi-nombre (el guion medio es el operador de resta), "mi nombre" (no puede tener espacios).
- Sensibilidad a mayúsculas: Edad y edad son dos variables completamente diferentes.

3. Tipos de datos fundamentales y type()
Qué son
Python clasifica la información en diferentes tipos para saber qué operaciones puede hacer con ellos. Los fundamentales son:
- str (String): Cadenas de texto.
- int (Integer): Números enteros (sin decimales).
- float (Float): Números de punto flotante (con decimales).
- bool (Boolean): Valores de verdad (True o False).
Ejemplo básico y type()
CÓDIGO:
nombre = "Ana"        # str
edad = 20           # int
estatura = 1.65     # float
es_estudiante = True  # bool
print(type(nombre))
print(type(estatura))
Explicación línea por línea
- 'nombre = "Ana"': Asigna un str. Siempre va entre comillas (simples o dobles).
- 'edad = 20': Asigna un int.
- 'estatura = 1.65': Asigna un float. Nota que usa punto (.), no coma (,).
- 'es_estudiante = True': Asigna un bool. Debe empezar con mayúscula (True, False), sin comillas.
- 'print(type(nombre))': La función type() inspecciona la variable y devuelve su tipo. print() lo muestra en pantalla.
4. La función len()
Qué es y para qué sirve
len() (de length = longitud) cuenta cuántos elementos hay dentro de algo. Principalmente lo usaremos ahora para contar cuántos caracteres tiene un string.
Ejemplo práctico
CÓDIGO:
mensaje = "Hola"
longitud = len(mensaje)
print(longitud)  # Imprime 4
Error frecuente
ERROR FRECUENTE: Intentar usar len() en un número (len(2026)). Causará un error TypeError, porque los números no tienen "longitud" de caracteres.
5. Conversión de tipos (Casting)
Qué es y para qué sirve
A veces necesitas cambiar un dato de un tipo a otro, por ejemplo, convertir un texto "10" al número 10 para poder sumarlo con otro número.
Sintaxis
Usamos int(), float(), str() y bool(). bool() comprueba el valor de verdad: bool(0) y bool("") producen False; bool(1) y bool("False") producen True. La cadena "False" no está vacía: bool() no interpreta su palabra como el booleano False.
Ejemplo básico
CÓDIGO:
texto_numero = "15"
numero_real = int(texto_numero)
resultado = numero_real + 5
print(resultado)  # Imprime 20
Errores de conversión
ERROR FRECUENTE: Intentar convertir texto que no contiene números: int("Hola") provocará un ValueError.
6. Entradas del usuario con input()
Qué es y para qué sirve
input() pausa el programa, muestra un mensaje y espera a que el usuario escriba algo y presione Enter. IMPORTANTE: input() SIEMPRE devuelve un str (cadena de texto), sin importar lo que el usuario escriba.
Ejemplo combinado con conversión
CÓDIGO:
edad_texto = input("¿Cuál es tu edad? ")
edad_numero = int(edad_texto)
# Todo en una sola línea (más común):
edad = int(input("¿Cuál es tu edad? "))
print(type(edad))
Explicación línea por línea (versión en una línea)
- 'input("¿Cuál es tu edad? ")': Muestra la pregunta y captura lo que escribes (por ejemplo, "25").
- 'int(...)': Toma ese "25" (que es texto) y lo convierte al número 25.
- 'edad = ...': Guarda el número resultante en la variable edad.
- 'print(type(edad))': Confirma que la variable ahora es de tipo int.

nombre = input("¿Cómo te llamas? ")

PARTE III — Operadores

En esta tercera parte, aprenderás a manipular la información. Los operadores son los símbolos que le dicen a Python qué operaciones matemáticas, de asignación o lógicas debe realizar con los datos.
1. Operadores Aritméticos
Qué es y para qué sirve
Son símbolos que realizan operaciones matemáticas básicas, igual que en una calculadora. Sirven para hacer cálculos con números (int y float).
Sintaxis y Tipos
- Suma: +
- Resta: -
- Multiplicación: *
- División (decimal): /
- División entera: // (redondea el cociente hacia abajo, hacia menos infinito).
- Módulo (residuo): % (lo que sobra de una división entera)
- Exponente: ** (elevar a una potencia)
Ejemplo básico
CÓDIGO:
a = 10
b = 3
print("Suma:", a + b)
print("División normal:", a / b)
print("División entera:", a // b)
print("Módulo o residuo:", a % b)
print("Exponente:", a ** b)
Explicación línea por línea
- 'a = 10' y 'b = 3': Se crean dos variables con valores enteros.
- 'print("Suma:", a + b)': Suma 10 y 3. Muestra 13.
- 'print("División normal:", a / b)': Divide 10 entre 3. Muestra 3.3333333333333335.
- print("División entera:", a // b): 10 // 3 muestra 3. Con negativos, -10 // 3 da -4, no -3: el resultado se redondea hacia abajo. Si ambos operandos son int, devuelve int; 10.0 // 3 devuelve 3.0 (float).
- 'print("Módulo o residuo:", a % b)': Si divides 10 entre 3, cabe 3 veces (3*3=9) y sobra 1. El módulo muestra ese 1. Es muy útil para saber si un número es par (numero % 2 == 0).
- 'print("Exponente:", a ** b)': Multiplica 10 por sí mismo 3 veces (10 * 10 * 10). Muestra 1000.
Error frecuente
ERROR FRECUENTE: División por cero (10 / 0). Python arrojará un error ZeroDivisionError porque matemáticamente no es posible.
2. Operadores de Asignación
Qué es y para qué sirve
Ya conoces = para asignar. Los operadores de asignación combinados son atajos para actualizar el valor de una variable haciendo una operación al mismo tiempo.
Sintaxis
En lugar de x = x + 1, puedes escribir x += 1. Funciona con +=, -=, *=, /=.
Ejemplo básico
CÓDIGO:
puntos = 10
puntos += 5   # Equivale a: puntos = puntos + 5
puntos -= 2   # Equivale a: puntos = puntos - 2
print(puntos)
Explicación línea por línea
- 'puntos = 10': Inicializa la variable con 10.
- 'puntos += 5': Toma los 10 puntos, le suma 5, y el nuevo total (15) lo guarda en la misma variable.
- 'puntos -= 2': Toma el valor actual (15), le resta 2, y guarda el nuevo total (13).
- 'print(puntos)': Muestra el valor final, que es 13.
3. Operadores de Comparación y = frente a ==
Qué es y para qué sirve
Sirven para comparar dos valores. El resultado de una comparación SIEMPRE es un valor booleano (True o False). Son la base para tomar decisiones en el código.
Diferencia crítica entre = y ==
- = (Un solo igual): ASIGNACIÓN. Guarda un valor en una variable. "La caja x ahora contiene el valor 5".
- == (Doble igual): COMPARACIÓN. Pregunta si dos cosas son iguales. "¿Lo que hay en x es igual a 5?".
Sintaxis de comparación
- Igual a: ==
- Diferente de: !=
- Mayor que: >
- Menor que: <
- Mayor o igual que: >=
- Menor o igual que: <=
Ejemplo básico
CÓDIGO:
edad = 18
print("¿Es adulto?:", edad >= 18)
print("¿Es un niño?:", edad < 12)
print("¿Tiene exactamente 18?:", edad == 18)
print("¿Es diferente de 20?:", edad != 20)
Explicación línea por línea
- 'edad = 18': Asignación (un solo =).
- 'edad >= 18': Evalúa si 18 es mayor o igual a 18. Como es igual, el resultado es True.
- 'edad < 12': Evalúa si 18 es menor que 12. Falso. Resultado: False.
- 'edad == 18': Evalúa si 18 es exactamente igual a 18. Resultado: True.
- 'edad != 20': Evalúa si 18 es distinto de 20. Como son diferentes, esto es True.
4. Operadores Lógicos (and, or, not)
Qué es y para qué sirve
Permiten combinar varias comparaciones al mismo tiempo.
- and (Y): Da True solo si TODAS las condiciones son verdaderas.
- or (O): Da True si AL MENOS UNA condición es verdadera.
- not (NO): Invierte el resultado (lo verdadero lo hace falso y viceversa).
Ejemplo básico
CÓDIGO:
tiene_identificacion = True
edad = 20
puede_entrar = (edad >= 18) and tiene_identificacion
print("¿Puede entrar al club?:", puede_entrar)
Explicación línea por línea
- 'tiene_identificacion = True': Variable booleana en verdadero.
- 'edad = 20': Variable entera con valor 20.
- '(edad >= 18) and tiene_identificacion': Primero evalúa edad >= 18 (que es True). Luego junta True and True. Como ambas son verdaderas, el resultado de and es True. Guarda ese resultado en puede_entrar.
- 'print(...)': Imprime True.
5. Precedencia y Uso de Paréntesis
Qué es
Si tienes una operación larga como 5 + 2 * 3, Python aplica reglas matemáticas (precedencia). Primero multiplicará (2 * 3 = 6) y luego sumará (5 + 6 = 11).
Buena práctica
BUENA PRÁCTICA: Aunque conozcas la precedencia de memoria, usa paréntesis para hacer el código más fácil de leer y forzar el orden que deseas.
CÓDIGO:
resultado = (5 + 2) * 3
# Aquí el resultado será 21.

PARTE IV — Condicionales

En esta cuarta parte, le daremos a tus programas la capacidad de tomar decisiones. Hasta ahora, el código se ejecutaba de arriba hacia abajo sin excepciones. Con los condicionales, el código puede elegir qué camino tomar basándose en ciertas situaciones.
1. La sentencia if, indentación y los dos puntos (:)
Qué es y para qué sirve
La instrucción if (si condicional) evalúa una condición. Si la condición es verdadera (True), ejecuta un bloque de código. Si es falsa (False), lo salta.
Sirve para que el programa reaccione diferente según los datos que reciba.
Sintaxis
Requiere la palabra if, seguida de la condición, y termina OBLIGATORIAMENTE con dos puntos (:). La siguiente línea debe tener "indentación" (espacios al inicio, generalmente 4) para indicarle a Python qué código pertenece al if.
Ejemplo básico
CÓDIGO:
edad = 20
if edad >= 18:
    print("Eres mayor de edad.")
    print("Puedes pasar.")
print("Fin del programa.")
Explicación línea por línea
- edad = 20: Se asigna el valor 20 a la variable entera edad.
- if edad >= 18:: Evalúa si 20 es mayor o igual a 18. Es True. Los : indican que empieza un bloque condicional.
-     print("Eres mayor..."): Al estar indentado, se ejecuta porque la condición fue verdadera.
-     print("Puedes pasar."): También está indentado, forma parte del bloque if.
- print("Fin del programa."): No tiene indentación. Se ejecuta SIEMPRE, sin importar la condición, porque está fuera del bloque if.
Error frecuente
- ERROR FRECUENTE: Olvidar los dos puntos : al final del if. Provoca un SyntaxError.
- ERROR FRECUENTE: No indentar o mezclar espacios y tabulaciones (IndentationError). En Python, la indentación define la estructura del código.
2. Las alternativas: else y elif
Qué es y para qué sirve
- else (si no): Se ejecuta cuando la condición del if es falsa.
- elif (else if - o si no, si...): Permite evaluar múltiples condiciones en cadena si la primera falla.
Ejemplo básico
CÓDIGO:
semaforo = "amarillo"

if semaforo == "verde":
    print("Puedes avanzar.")
elif semaforo == "amarillo":
    print("Precaución, frena.")
elif semaforo == "rojo":
    print("Detente completamente.")
else:
    print("Color no reconocido.")
Explicación línea por línea
- semaforo = "amarillo": Guarda el string en la variable.
- if semaforo == "verde":: Es falso, por lo que salta su bloque indentado.
- elif semaforo == "amarillo":: Como el if falló, evalúa esto. Es verdadero, así que imprime "Precaución, frena.".
- El resto del bloque (elif "rojo" y else) se ignora automáticamente porque ya se cumplió una condición.
3. Condiciones Múltiples (and, or, not)
Qué es y para qué sirve
Puedes combinar varias preguntas en una sola línea usando los operadores lógicos que aprendiste en la parte anterior.
Ejemplo práctico
CÓDIGO:
edad = 25
tiene_licencia = True
esta_ebrio = False

if edad >= 18 and tiene_licencia and not esta_ebrio:
    print("Puedes conducir el vehículo.")
else:
    print("No cumples los requisitos para conducir.")
Buena práctica
BUENA PRÁCTICA: Cuando uses muchas condiciones, puedes usar paréntesis para agruparlas y hacer el código más legible: if (edad >= 18) and (tiene_licencia):.
4. Condicionales Anidados
Qué es y para qué sirve
Es colocar un if dentro de otro if. Sirve para tomar decisiones jerárquicas (primero compruebas algo general y, si se cumple, compruebas algo más específico).
Ejemplo básico
CÓDIGO:
usuario = "admin"
contrasena = "1234"

if usuario == "admin":
    print("Usuario reconocido.")
    if contrasena == "1234":
        print("Acceso concedido.")
    else:
        print("Contraseña incorrecta.")
else:
    print("Usuario no encontrado.")
5. Comparación de Strings y Diferencia = vs ==
Diferencia crítica
Recuerda: = asigna un valor. == compara valores.
Si escribes if edad = 18: Python arrojará un error de sintaxis porque estás intentando asignar un valor dentro de una pregunta.
Comparación y validación básica de entradas
Al comparar texto (strings), debes recordar que las mayúsculas importan. "hola" no es igual a "Hola".
CÓDIGO:
respuesta = input("¿Deseas continuar? (si/no): ")
if respuesta == "si" or respuesta == "SI" or respuesta == "Si":
    print("Continuando...")
else:
    print("Proceso detenido.")

PARTE V — Colecciones

En esta quinta parte, aprenderás a guardar múltiples valores en una sola variable. Hasta ahora, una variable era como una caja con un solo objeto. Las colecciones son como cajas organizadoras con muchos compartimentos.
1. Listas (list)
Qué son y para qué sirven
Una lista es una colección ordenada y modificable (mutable) de elementos. Sirven para almacenar secuencias de datos, como una lista de compras, nombres de usuarios o puntuaciones en un juego.
Sintaxis y Creación
Se crean usando corchetes [] y separando los elementos con comas.
CÓDIGO:
vacia = []
frutas = ["manzana", "banana", "cereza"]
edades = [20, 25, 30, 35]
mixta = ["Juan", 28, True, 1.75]
Índices positivos, negativos y acceso
Cada elemento tiene una posición llamada "índice". ¡En Python, empezamos a contar desde 0!
- Índice positivo: 0 (primero), 1 (segundo), 2 (tercero)...
- Índice negativo: -1 (último), -2 (penúltimo)...
CÓDIGO:
colores = ["rojo", "verde", "azul", "amarillo"]
print(colores[0])   # rojo
print(colores[-1])  # amarillo
Modificación y Operador in
Puedes cambiar el valor de un elemento usando su índice. El operador in verifica si un valor existe dentro de la lista.
CÓDIGO:
juegos = ["Zelda", "Mario", "Halo"]
juegos[1] = "Sonic"
print(juegos)
print("Halo" in juegos)
Explicación línea por línea
- juegos = [...]: Crea la lista con 3 strings.
- juegos[1] = "Sonic": Va a la posición 1 (que era "Mario") y lo reemplaza por "Sonic".
- print(juegos): Imprime ['Zelda', 'Sonic', 'Halo'].
- print("Halo" in juegos): Pregunta si "Halo" está en la lista. Devuelve True.
Métodos principales (append, insert, remove, pop) y len()
- append(elemento): Añade al final.
- insert(índice, elemento): Añade en una posición específica.
- remove(elemento): Elimina la primera coincidencia del valor.
- pop(índice): Elimina y devuelve el elemento en esa posición (por defecto, el último).
- len(lista): Devuelve la cantidad de elementos.
CÓDIGO:
letras = ["A", "B", "C"]
letras.append("D")
letras.insert(1, "X")
letras.remove("C")
eliminada = letras.pop()
print(letras)
print("Longitud:", len(letras))
Errores frecuentes
- ERROR FRECUENTE: IndexError: Ocurre si intentas acceder a un índice que no existe (ej. letras[10]).
2. Tuplas (tuple)
Qué son y para qué sirven
Las tuplas son secuencias inmutables: no puedes reemplazar, añadir ni quitar sus posiciones. Sin embargo, si contienen una lista, esa lista sí puede cambiar. Sirven para agrupar datos cuya estructura se mantendrá fija.
Sintaxis
Normalmente la coma crea la tupla: t = 1, 2 equivale a t = (1, 2). Los paréntesis agrupan y a veces son necesarios por la sintaxis. La tupla vacía se escribe ().
CÓDIGO:
coordenadas = (10.5, -4.2)
print(coordenadas[0])
# coordenadas[0] = 11.0  # ESTO CAUSARÍA UN ERROR
Tupla de un solo elemento
Una tupla de un elemento necesita coma: ("único",). En cambio, ("único") es una cadena str entre paréntesis; no es una tupla.
CÓDIGO:
tupla_sola = ("único",)
no_es_tupla = ("único")
Errores frecuentes
- ERROR FRECUENTE: TypeError: Intentar modificar (tupla[0] = "algo"), agregar o eliminar elementos de una tupla.
3. Diccionarios (dict)
Qué son y para qué sirven
Colecciones que almacenan datos en pares "clave-valor" (key-value). En lugar de usar índices numéricos, usas una palabra (clave) para buscar su significado (valor), igual que en un diccionario real.
Sintaxis y Creación
Se usan llaves {}. Cada par se separa con dos puntos : y los elementos con comas.
CÓDIGO:
usuario = {
    "nombre": "Ana",
    "edad": 28,
    "rol": "admin"
}
Acceso, Modificación y Nuevas Claves
CÓDIGO:
print(usuario["nombre"])  # Acceso
usuario["edad"] = 29      # Modificación
usuario["pais"] = "México" # Nueva clave
print(usuario)
Métodos principales (get, keys, values, items)
- get(clave, valor_por_defecto): Forma segura de acceder a un valor sin causar error si no existe.
- keys(): Devuelve todas las claves.
- values(): Devuelve todos los valores.
- items(): Devuelve pares de clave y valor.
CÓDIGO:
# Usando el diccionario 'usuario' anterior
print(usuario.get("telefono", "No registrado"))
del usuario["rol"] # Elimina la clave 'rol'
Errores frecuentes
- ERROR FRECUENTE: KeyError: Intentar acceder a una clave que no existe usando corchetes (ej. usuario["telefono"]). Por eso a veces es mejor usar get().
4. Conjuntos (set)
Qué son y para qué sirven
Son colecciones desordenadas de elementos únicos. Sirven para eliminar duplicados de una lista rápidamente o para realizar operaciones matemáticas de conjuntos (uniones, intersecciones).
Sintaxis
Se usan llaves {}, pero solo con valores, sin los dos puntos : (eso lo diferencia de un diccionario).
CÓDIGO:
numeros = {1, 2, 3, 3, 3, 4}
print(numeros)  # Imprime {1, 2, 3, 4} (duplicados eliminados)
Métodos principales
CÓDIGO:
numeros.add(5)
numeros.remove(2)  # Da error si no existe
numeros.discard(10) # Igual que remove, pero NO da error si no existe
Operaciones básicas
CÓDIGO:
set_a = {1, 2, 3}
set_b = {3, 4, 5}
print("Unión:", set_a | set_b)          # Todo: {1, 2, 3, 4, 5}
print("Intersección:", set_a & set_b)   # Comunes: {3}
print("Diferencia:", set_a - set_b)     # En A pero no en B: {1, 2}
Errores frecuentes
- ERROR FRECUENTE: Confundir {}. Si escribes vacio = {}, creas un diccionario vacío, no un conjunto. Para crear un conjunto vacío debes usar vacio = set().

6. Indexación y slicing (Rebanado)
Qué es
El "slicing" te permite extraer una porción o sub-lista. La sintaxis es lista[inicio:fin]. (El 'inicio' se incluye, pero el 'fin' NO se incluye).
Explicación detallada
CÓDIGO:
datos = ["A", "B", "C", "D", "E"]
print(datos[0])    # "A" (Índice 0)
print(datos[-1])   # "E" (Último elemento)
print(datos[1:4])  # ["B", "C", "D"] (Del 1 al 3)
print(datos[:3])   # ["A", "B", "C"] (Desde el principio hasta el 2)
print(datos[2:])   # ["C", "D", "E"] (Desde el 2 hasta el final)
7. Colecciones combinadas (Anidadas)
Qué es
Puedes meter colecciones dentro de otras colecciones.
Ejemplos sencillos

# Lista de diccionarios
usuarios = [{"nombre": "Ana"}, {"nombre": "Luis"}]
print(usuarios[1]["nombre"]) # Luis
# Diccionario con listas
curso = {"materia": "Python", "alumnos": ["Ana", "Juan", "Pedro"]}
print(curso["alumnos"][0]) # Ana

PARTE VI — Bucles

En esta sexta parte, aprenderás a automatizar tareas repetitivas. Los bucles le permiten a tu código ejecutar las mismas instrucciones una y otra vez sin que tengas que escribirlas múltiples veces.
1. Qué es un bucle
Qué es y para qué sirve
Un bucle (o ciclo) es una estructura que repite un bloque de código mientras se cumpla una condición o hasta que termine de recorrer una colección de elementos.
Sirve para la repetición automática. En lugar de escribir print("Hola") 100 veces manualmente, escribes un bucle de tres líneas que lo hace por ti al instante, reduciendo errores y ahorrando tiempo.
2. El bucle for
Qué es y para qué sirve
El bucle for se utiliza para iterar (recorrer) una secuencia o colección (como una lista, una tupla, un diccionario, un set o un string).
Sintaxis
CÓDIGO:
nombres = ["Ana", "Luis", "Carlos"]
for nombre in nombres:
    print(nombre)
Explicación línea por línea
- nombres = [...]: Creamos una lista llamada nombres (el "iterable").
- for nombre in nombres:: Inicia el bucle. nombre es la "variable de iteración", una variable temporal que tomará el valor de cada elemento de la lista uno por uno.
-     print(nombre): Debe llevar indentación. En la primera vuelta imprime "Ana", en la segunda "Luis", y en la tercera "Carlos".
Recorrido de strings
Un string también es una secuencia de caracteres, por lo que puedes recorrerlo con for.
CÓDIGO:
palabra = "Python"
for letra in palabra:
    print(letra)
# Imprimirá P, luego y, luego t... en líneas separadas.
3. La función range()
Qué es y para qué sirve
range() genera una secuencia de números. Es extremadamente útil cuando necesitas que un bucle se ejecute un número específico de veces.
Sintaxis y argumentos
- range(5): Genera números desde 0 hasta 4. (El límite final NO se incluye).
- range(1, 6): Genera números desde el 1 (inicio) hasta el 5 (fin, recuerda que el 6 se excluye).
- range(0, 10, 2): Genera números desde 0 hasta 9, saltando de 2 en 2 (paso). Resultado: 0, 2, 4, 6, 8.
4. Bucle for con range()
Ejemplo de contadores sencillos
CÓDIGO:
for numero in range(1, 6):
    print("Contando:", numero)
Explicación
Este código imprimirá "Contando: 1", luego "Contando: 2", hasta el 5. La variable temporal numero toma los valores que genera range(1, 6).
5. El bucle while
Qué es y para qué sirve
El bucle while (mientras) repite un bloque de código mientras una condición específica siga siendo verdadera (True).
Ejemplo básico
CÓDIGO:
contador = 1
while contador <= 5:
    print(contador)
    contador += 1
Explicación línea por línea
- contador = 1: Inicializa la variable antes del bucle.
- while contador <= 5:: Evalúa la condición de continuación. Si es True, entra al bucle.
-     print(contador): Imprime el valor actual (ej. 1).
-     contador += 1: ¡CRÍTICO! Es la actualización de la variable. Suma 1 al contador. Si olvidas esta línea, el contador siempre será 1, la condición siempre será verdadera, y el bucle nunca terminará.
6. Bucles infinitos
Qué son y por qué ocurren
Ocurren cuando la condición de un bucle while nunca se vuelve falsa. Generalmente es un error (olvidar actualizar la variable de control).
Ejemplo seguro de corrección
CÓDIGO:
# Incorrecto (Infinito):
# x = 1
# while x > 0:
#     print(x)
# Correcto:
x = 1
while x > 0 and x < 5:
    print(x)
    x += 1 # La condición eventualmente será falsa
7. La instrucción break
Qué es y para qué sirve
break sirve para terminar y salir del bucle inmediatamente, sin importar si la colección se terminó de recorrer o si la condición del while sigue siendo verdadera.
Ejemplo
CÓDIGO:
for num in range(1, 10):
    if num == 5:
        print("Encontramos el 5. Deteniendo.")
        break
    print(num)
# Imprimirá 1, 2, 3, 4 y luego se detendrá.
8. La instrucción continue
Qué es y para qué sirve
continue detiene la iteración actual y salta directamente a la siguiente vuelta del bucle, pero NO rompe el bucle por completo.
Comparación y ejemplo
- break = terminar todo el bucle.
- continue = saltar solo el paso actual.
CÓDIGO:
for num in range(1, 6):
    if num == 3:
        continue # El 3 se salta
    print(num)
# Imprimirá 1, 2, 4, 5 (nota que falta el 3).
9. Condicionales dentro de bucles
Ejemplo práctico
Podemos combinar for / while con if para filtrar datos.
CÓDIGO:
numeros = [10, 15, 20, 25, 30]
for n in numeros:
    if n % 2 == 0:
        print(n, "es par")
    else:
        print(n, "es impar")
10. Bucles anidados
Qué son
Es colocar un bucle dentro de otro. El bucle interno completa todas sus vueltas por cada vuelta del bucle externo.
Ejemplo básico
CÓDIGO:
for fila in range(3):
    for columna in range(3):
        print("Fila:", fila, "- Columna:", columna)
Explicación
Por cada fila (0, 1, 2), el bucle interno de columna cuenta (0, 1, 2). Esto genera coordenadas como (0,0), (0,1), (0,2), luego (1,0), etc.
11. Errores frecuentes
- ERROR FRECUENTE: Olvidar actualizar la variable en un while, causando un bucle infinito.
- ERROR FRECUENTE: Mala indentación. Todo lo que deba repetirse debe estar indentado dentro del bucle.
- ERROR FRECUENTE: Usar incorrectamente range() pensando que incluye el último número (ej. range(1, 10) se detiene en 9).
- ERROR FRECUENTE: Confundir break (sale de todo) con continue (sale del paso actual).
- ERROR FRECUENTE: Modificar una lista (añadir o borrar elementos) mientras la estás recorriendo con un for. Esto causa comportamientos impredecibles.

PARTE VII — Funciones

En esta séptima parte, aprenderás a empaquetar tu código. Las funciones te permiten agrupar instrucciones bajo un nombre para que puedas reutilizarlas cuantas veces quieras, haciendo tu código más limpio, organizado y profesional.
1. Qué es una función
Qué es y qué problema resuelve
Una función es un bloque de código diseñado para realizar una tarea específica. 
Resuelve el problema de la repetición: si tienes una fórmula matemática o un proceso de validación que necesitas usar en 10 partes distintas de tu programa, en lugar de copiar y pegar el código 10 veces, lo escribes una sola vez dentro de una función y simplemente la "llamas" cuando la necesites.
Esto mejora la organización (tu código se divide en partes lógicas) y la reutilización (ahorras tiempo y evitas errores por copiar/pegar).
2. La instrucción def
Definir vs Llamar
Para crear una función usamos la palabra clave `def` (de definir). 
- Definir una función: Es crearla y decirle a Python qué debe hacer. Esto NO ejecuta el código, solo lo guarda en la memoria.
- Llamar una función: Es darle la orden a Python de que ejecute el código que guardaste previamente.
Sintaxis y Ejemplo básico
CÓDIGO:
# 1. Definir la función
def saludar():
    print("¡Hola, bienvenido al sistema!")

# 2. Llamar a la función
saludar()
saludar()
Explicación línea por línea
- `def saludar():`: `def` indica que vamos a crear una función. `saludar` es el nombre que le damos (usa snake_case). Los paréntesis `()` son obligatorios, y los dos puntos `:` indican que empieza el bloque de código.
- `    print("¡Hola...")`: Este código está indentado. Es el cuerpo de la función. No se ejecutará hasta que llamemos a la función.
- `saludar()`: Esta línea NO tiene indentación. Aquí estamos "llamando" o "invocando" a la función. Al ejecutar esto, Python busca la función `saludar` y ejecuta su contenido. Al llamarla dos veces, el saludo se imprimirá dos veces.
3. Parámetros y argumentos
Qué son y para qué sirven
A menudo, las funciones necesitan información para trabajar. 
- Parámetro: Es la variable que definimos dentro de los paréntesis al crear la función. Es como un espacio en blanco que espera ser llenado.
- Argumento: Es el valor real (el dato) que le enviamos a la función cuando la llamamos.
Ejemplo claro
CÓDIGO:
# 'nombre' es el PARÁMETRO
def saludar_usuario(nombre):
    print("Hola", nombre)

# "Ana" y "Carlos" son los ARGUMENTOS
saludar_usuario("Ana")
saludar_usuario("Carlos")
Explicación
Cuando escribimos `saludar_usuario("Ana")`, el argumento `"Ana"` viaja hasta la función y se guarda en el parámetro `nombre`. Luego, la función imprime "Hola Ana".
4. Varios parámetros
Sintaxis
Puedes pasar múltiples datos separándolos por comas.
CÓDIGO:
def sumar_imprimir(a, b):
    resultado = a + b
    print("La suma es:", resultado)

sumar_imprimir(10, 5)
5. El uso de return (vs print)
Diferencia CRÍTICA
Este es el concepto donde más se confunden los principiantes.
- `print()`: Solo muestra un texto en la pantalla para que el humano lo lea. El programa no puede usar ese texto para seguir calculando.
- `return`: Devuelve un valor al lugar donde la función fue llamada, permitiendo que el programa guarde ese dato en una variable o lo use para otra operación matemática. Cuando Python lee un `return`, la función termina inmediatamente.
Ejemplo paso a paso
CÓDIGO:
def sumar(a, b):
    return a + b

resultado = sumar(5, 3)
print("El resultado devuelto es:", resultado)
Explicación línea por línea
- `def sumar(a, b):`: Crea la función con dos parámetros.
- `    return a + b`: Suma `a` y `b`, y devuelve el resultado. NO lo imprime.
- `resultado = sumar(5, 3)`: Python llama a `sumar(5, 3)`. La función calcula `5 + 3` y devuelve un `8`. Ese `8` viaja de regreso y se guarda en la variable `resultado`.
- `print(..., resultado)`: Finalmente, mostramos el valor guardado en la variable.

11. Variables locales y globales
Ámbito (Scope)
- Variable local: Su nombre pertenece al ámbito de la función y normalmente no se accede a él desde fuera. Al terminar la llamada no se destruyen necesariamente sus objetos: otros objetos, valores devueltos o funciones internas pueden conservar referencias.
- Variable global: Su nombre se define en el ámbito del módulo. No queda disponible automáticamente en todos los módulos de un programa.
Buenas prácticas
BUENA PRÁCTICA: Evita usar (y sobre todo modificar) variables globales dentro de tus funciones. Trata a tus funciones como cajas negras: todo lo que necesitan deben recibirlo como argumentos (parámetros), y todo lo que producen deben entregarlo usando `return`.
12. Errores frecuentes
- ERROR FRECUENTE: Definir una función pero nunca llamarla. Tu programa no hará nada y no mostrará errores, simplemente terminará.
- ERROR FRECUENTE: Olvidar los paréntesis al llamar la función: `saludar` en vez de `saludar()`.
- ERROR FRECUENTE: Olvidar los `:` al final de `def` (SyntaxError).
- ERROR FRECUENTE: Pasar una cantidad incorrecta de argumentos. Si la función pide 2 y pasas 1, Python lanzará un `TypeError`.
- ERROR FRECUENTE: Confundir `print` con `return`. Si una función solo imprime y tú intentas guardar su resultado en una variable (ej. `x = funcion_con_print()`), esa variable guardará un valor especial llamado `None` (Nada).
- ERROR FRECUENTE: Intentar usar una variable local fuera de su función (NameError).

PARTE VIII — Strings

En esta octava parte, exploraremos a fondo los "strings" (cadenas de texto). Aunque ya los has usado para imprimir mensajes, los strings son una de las herramientas más poderosas y versátiles en Python. Aprenderás a manipular, buscar, limpiar y dar formato al texto como un profesional.
1. Qué es un string
Qué es y qué representa
Un string es una secuencia de caracteres (letras, números, espacios, símbolos) que representa texto. 
Se definen encerrando el contenido entre comillas simples ('Hola') o dobles ("Hola"). Python no hace diferencia funcional entre ambas.
Diferencia entre texto y variables
CÓDIGO:
mensaje = "Python"
print("mensaje")
print(mensaje)
Explicación línea por línea
- `mensaje = "Python"`: Asignamos el string `"Python"` a la variable llamada `mensaje`.
- `print("mensaje")`: Al llevar comillas, Python imprime literalmente la palabra "mensaje".
- `print(mensaje)`: Al no llevar comillas, Python busca la variable y muestra su contenido ("Python").
Strings vacíos
Puedes crear un string que no contenga nada. Es muy útil como punto de partida para construir texto dinámicamente.
CÓDIGO:
texto_vacio = ""
2. Indexación
Qué es y para qué sirve
Cada carácter en un string tiene una posición numérica llamada "índice". ¡Recuerda que en Python siempre empezamos a contar desde el cero (0)!
Índices positivos y negativos
CÓDIGO:
texto = "Python"
print(texto[0])
print(texto[-1])
Explicación línea por línea
- `texto = "Python"`: Creamos la variable. P = 0, y = 1, t = 2, h = 3, o = 4, n = 5.
- `print(texto[0])`: Accede al primer carácter (índice 0). Imprime `P`.
- `print(texto[-1])`: Python permite índices negativos para contar desde el final. `-1` es el último carácter. Imprime `n`.
Errores por índice fuera de rango
Si intentas acceder a `texto[10]`, Python lanzará un `IndexError: string index out of range` porque la palabra solo tiene 6 caracteres.
3. La función len()
Cómo conocer la longitud
Para saber cuántos caracteres tiene un string (incluyendo espacios), usamos `len()` (de *length*, longitud).
CÓDIGO:
saludo = "Hola, mundo"
longitud = len(saludo)
print(longitud) # Imprime 11
4. Slicing (Rebanado)
Qué es
El slicing te permite extraer un "trozo" (subcadena) de un string.
La sintaxis completa es `[inicio : fin : paso]`. El carácter de "inicio" se incluye, pero el de "fin" NO se incluye.
Ejemplos paso a paso
CÓDIGO:
texto = "Programacion"
print(texto[0:3])
print(texto[:3])
print(texto[2:])
print(texto[::2])
Explicación línea por línea
- `texto[0:3]`: Extrae desde el índice 0 hasta el 2 (el 3 no se incluye). Imprime `Pro`.
- `texto[:3]`: Si omites el inicio, Python asume que es 0. Imprime `Pro`.
- `texto[2:]`: Si omites el fin, Python extrae hasta el último carácter. Extrae desde la 'o' en adelante. Imprime `ogramacion`.
- `texto[::2]`: Omitir inicio y fin significa "todo el texto", pero el `2` al final indica el "paso" (saltar de dos en dos). Imprime `Pormco`.
5. Inmutabilidad
Qué es
Los strings en Python son inmutables. Esto significa que, una vez creados, no puedes cambiar un carácter individual directamente.
Error de inmutabilidad
CÓDIGO:
palabra = "Gato"
# palabra[0] = "P"  # ESTO CAUSA UN ERROR (TypeError)
La solución: Crear un nuevo string
CÓDIGO:
palabra_nueva = "P" + palabra[1:]
print(palabra_nueva) # Imprime "Pato"

Qué es
Concatenar es unir dos o más strings usando el operador de suma (`+`).

9. Métodos básicos de strings
Los métodos son "funciones" especiales que pertenecen a los strings. Importante: Como los strings son inmutables, estos métodos no modifican el texto original, sino que devuelven un nuevo string con los cambios.
Transformación de texto
CÓDIGO:
mensaje = "  hola MUNDO  "
print(mensaje.lower())      # "  hola mundo  " (Todo minúsculas)

CÓDIGO:

10. El método split()
Qué es y para qué sirve
`split()` divide un string en varias partes y las guarda en una Lista. Por defecto, divide el texto cada vez que encuentra un espacio.
CÓDIGO:
frase = "Python es muy útil"
palabras = frase.split()
print(palabras) # Imprime: ['Python', 'es', 'muy', 'útil']
11. El método join()
Qué es y para qué sirve
Es el inverso de `split()`. Toma una lista de strings y los une en un solo string, usando un "conector" (separador).
CÓDIGO:
palabras = ["Python", "es", "útil"]
frase = " ".join(palabras) # Usa un espacio " " como conector
print(frase) # Imprime: Python es útil
Comparación: split() frente a join()
- `split()`: Pasa de String a Lista.
- `join()`: Pasa de Lista a String.
12. f-strings (String Formatting)
Qué es y para qué sirve
A partir de Python 3.6, las "f-strings" son la forma más moderna, rápida y legible de insertar variables dentro de un texto.
Sintaxis y Ejemplo
Debes colocar una `f` justo antes de las comillas iniciales, y meter las variables entre llaves `{}`.
CÓDIGO:
nombre = "Ana"
edad = 20
print(f"Me llamo {nombre} y tengo {edad} años.")
Expresiones dentro de f-strings
Las llaves evalúan expresiones. Los float representan muchos decimales de forma aproximada: con precio = 100, precio * 1.16 produce 115.99999999999999. El formato :.2f muestra 116.00, pero no cambia la precisión interna del cálculo. Fuente: Representación de punto flotante
CÓDIGO:
precio = 100
print(f"El total con impuestos es: {precio * 1.16:.2f}")
13. Caracteres de escape
Qué son
Son combinaciones especiales que usan la barra invertida `\` para insertar caracteres que normalmente romperían el string o que no se pueden escribir directamente.
- `\n`: Nueva línea (Enter).
- `\t`: Tabulación (Sangría).
- `\"` y `\'`: Comilla doble o simple literal.
- `\\`: Barra invertida literal.
CÓDIGO:

print("Él dijo: \"Hola\"")
print("Ruta:\\Carpeta\\Archivo")

20. Errores frecuentes
- Índice fuera de rango: Intentar `texto[100]` en una palabra corta.
- Intentar modificar directamente: `texto[0] = "A"` (falla por inmutabilidad).
- Olvidar comillas: `texto = Hola` (Python pensará que `Hola` es una variable).
- Concatenar str con int sin conversión: `"Tengo " + 20 + " años"` (TypeError). Correcto: `"Tengo " + str(20) + " años"` o usar f-strings.
- Confundir split() con join(): Tratar de hacer `.join()` a un string en lugar de una lista.
- Olvidar guardar el resultado: Como los strings son inmutables, `texto.lower()` por sí solo no cambia la variable `texto`. Debes hacer `texto = texto.lower()`.
- Uso incorrecto de escapes: Usar `\n` pensando que imprimirá una barra y una ene. Si quieres el texto literal "\n", debes usar `\\n`.

PARTE IX — Archivos

En esta novena parte, daremos un paso gigantesco. Hasta ahora, todos los datos que guardabas en variables se perdían al cerrar el programa. Aquí aprenderás a interactuar con el disco duro para guardar y recuperar información de forma permanente.
1. Qué es un archivo
Qué es y para qué sirve
Cuando declaras una variable (nombre = "Ana"), se guarda en la memoria RAM (memoria a corto plazo). Si apagas la computadora o cierras el programa, la RAM se limpia y los datos desaparecen. 
Un archivo es una estructura guardada en el disco duro (memoria a largo plazo). Sirve para lograr la persistencia de la información. Un archivo de texto (.txt) almacena datos como simples cadenas de caracteres. Piensa en las listas de tareas en un bloc de notas, registros de temperaturas o una agenda de contactos.
2. open()
Qué es y para qué sirve
Para interactuar con un archivo, primero debes "abrirlo", creando un puente de comunicación entre tu programa y el disco duro. Usamos la función incorporada open().
Sintaxis
CÓDIGO:
archivo = open("datos.txt", "r", encoding="utf-8")
Explicación línea por línea
- archivo =: Guardamos el "puente" o manejador del archivo en una variable.
- open(...): Es la función que abre el archivo.
- "datos.txt": Es el nombre (o ruta) del archivo que queremos abrir.
- "r": Es el modo de apertura. "r" viene de read (leer).
- encoding="utf-8": Le dice a Python qué "diccionario de caracteres" usar. Es crucial para leer correctamente acentos y la letra ñ.
3. read()
Qué es y para qué sirve
Una vez abierto el archivo, read() extrae TODO su contenido como un único y gigantesco string.
Ejemplo
CÓDIGO:
archivo = open("datos.txt", "r", encoding="utf-8")
contenido = archivo.read()
print(contenido)
archivo.close()
4. readline()
Qué es y para qué sirve
Si el archivo es muy largo, quizá no quieras leerlo todo de golpe. readline() lee solo una línea cada vez que lo llamas (desde donde se quedó la última vez).
CÓDIGO:
archivo = open("datos.txt", "r", encoding="utf-8")
linea1 = archivo.readline()
linea2 = archivo.readline()
print("Línea 1:", linea1)
archivo.close()
5. readlines()
Qué es y para qué sirve
readlines() (en plural) lee todo el archivo, pero en lugar de devolver un solo texto, devuelve una Lista donde cada elemento es una línea del archivo.
CÓDIGO:
archivo = open("datos.txt", "r", encoding="utf-8")
lineas = archivo.readlines()
print(lineas[0]) # Imprime la primera línea
archivo.close()
6. close()
Por qué es vital
Cerrar un archivo libera recursos y vacía los datos pendientes del búfer. Si no se cierra correctamente, parte de lo escrito podría no guardarse. No implica que todo archivo abierto esté bloqueado por el sistema operativo. Usa with open(...) para cerrarlo incluso si se produce una excepción.
7. with open()
Qué es y por qué es la mejor práctica
Es fácil olvidar escribir close(). La estructura with open() (gestor de contexto) se encarga de cerrar el archivo automáticamente en el instante en que el bloque de código indentado termina o incluso si ocurre un error inesperado.
Ejemplo
CÓDIGO:
with open("datos.txt", "r", encoding="utf-8") as archivo:
    contenido = archivo.read()
    print(contenido)
# Aquí el archivo ya está cerrado automáticamente
Explicación
- with: Inicia el bloque seguro.
- open(...): Abre el archivo.
- as archivo:: Asigna el manejador a la variable archivo. Fíjate en los dos puntos :.
- contenido = ...: Todo lo que esté indentado ocurrirá mientras el archivo esté abierto.
8. Modos de apertura
Cuando abres un archivo, debes declarar tu intención:
- "r" (Read): Solo lectura. El archivo debe existir, de lo contrario da error.
- "w" (Write): Escritura. ¡CUIDADO! Si el archivo ya existe, borra todo su contenido y lo sobrescribe desde cero. Si no existe, lo crea.
- "a" (Append): Agregar. Añade contenido al final del archivo sin borrar lo anterior. Si no existe, lo crea.
- "x" (Create): Crea un archivo nuevo. Si ya existe, lanza un error (ideal para no sobrescribir accidentalmente).
9. Escritura ("w")
Ejemplo
CÓDIGO:
with open("notas.txt", "w", encoding="utf-8") as archivo:
    archivo.write("Primera línea\n")
    archivo.write("Segunda línea\n")
10. Agregar contenido ("a")
Ejemplo
CÓDIGO:
with open("notas.txt", "a", encoding="utf-8") as archivo:
    archivo.write("Esta línea se añade al final\n")
Diferencia w vs a
Cada apertura en modo "w" trunca el archivo existente. Si lo abres diez veces y escribes una línea cada vez, al final queda la última. Si lo abres una sola vez y llamas diez veces a write() con un salto de línea, puedes guardar diez líneas. El modo "a" añade contenido al final.
11. Leer línea por línea
La forma más eficiente
La mejor manera de procesar un archivo, sin importar si tiene 10 o 1 millón de líneas, es iterarlo con un bucle for.
CÓDIGO:
with open("datos.txt", "r", encoding="utf-8") as archivo:
    for linea in archivo:
        print(linea.strip())
Explicación
- for linea in archivo:: Lee el archivo línea por línea, sin cargar todo en la RAM.
- linea.strip(): Quita el salto de línea \n oculto al final de cada frase y los espacios sobrantes.
12. Archivos + Listas
Cómo guardar datos en la memoria a partir de un archivo
CÓDIGO:
nombres = []
with open("nombres.txt", "r", encoding="utf-8") as archivo:
    for linea in archivo:
        nombre_limpio = linea.strip()
        nombres.append(nombre_limpio)
print("Nombres cargados:", nombres)
13. Archivos + input()
Interacción con el usuario
CÓDIGO:
nuevo_usuario = input("Ingresa tu nombre: ")

    archivo.write(nuevo_usuario + "\n")

14. Codificación UTF-8
¿Por qué lo usamos?
Indica encoding="utf-8" al leer y escribir archivos de texto UTF-8. En Python 3.14 la codificación predeterminada depende de la configuración regional y del modo UTF-8; no siempre es cp1252 en Windows. PEP 686 establece el modo UTF-8 predeterminado desde Python 3.15, con opciones para desactivarlo. Leer un archivo con una codificación distinta de la usada al escribirlo puede producir errores o texto incorrecto. Fuente: PEP 686: modo UTF-8 predeterminado
15. Rutas relativas
Una ruta relativa se interpreta desde el directorio de trabajo actual, que puedes consultar con Path.cwd() tras importar Path. Puede ser distinto de la carpeta donde está el script.
- "datos.txt": Busca el archivo dentro del directorio de trabajo actual.
- "carpeta/datos.txt": Busca dentro de carpeta, una subcarpeta del directorio de trabajo actual.
16. Rutas absolutas
Una ruta absoluta es la dirección completa y exacta desde la raíz del disco duro.
- Ejemplo ilustrativo en Windows: "C:/Users/Juan/Desktop/datos.txt". Sustituye usuario y carpetas por los reales; el Escritorio puede estar redirigido.
- Ejemplo ilustrativo en macOS: "/Users/juan/Desktop/datos.txt". En Linux: "/home/juan/datos.txt". Ninguna de estas rutas garantiza que exista en tu equipo.
Una ruta absoluta identifica una ubicación desde la raíz; una relativa depende del directorio de trabajo. Su portabilidad depende de la estructura y configuración: una ruta absoluta también podría existir en otro equipo.
17. Introducción a pathlib
Qué es
pathlib es un módulo moderno de Python que hace que trabajar con rutas sea mucho más fácil y seguro, sin importar si estás en Windows o Mac.
Ejemplo
CÓDIGO:
from pathlib import Path
ruta = Path("datos.txt")  # Relativa al directorio de trabajo
# En un archivo .py, para ubicarlo junto al script:
ruta_junto_al_script = Path(__file__).resolve().parent / "datos.txt"
# __file__ normalmente no existe en una consola o notebook.
18. Comprobar existencia

CÓDIGO:

20. iterdir()

21. FileNotFoundError
Si intentas hacer open("no_existo.txt", "r"), Python arrojará un error FileNotFoundError y el programa se detendrá. En la siguiente sección (Excepciones) veremos cómo evitar que el programa colapse cuando esto suceda.
22. Buenas prácticas
- Preferir siempre with open() en lugar de open() y close() manuales.
- Usar siempre encoding="utf-8" al leer o escribir texto.
- No sobrescribir ("w") archivos importantes accidentalmente; usar "a" o crear copias de seguridad.
- Comprobar las rutas con Path(ruta).exists().
- Separar datos (archivos .txt) de tu código fuente (.py).
23. Errores frecuentes

- ERROR FRECUENTE: Olvidar cerrar el archivo (si no usas with open()).

- ERROR FRECUENTE: Intentar hacer archivo.read() después de que el bloque with open() ha terminado (ValueError: I/O operation on closed file).

PARTE X — Errores y excepciones

En esta décima parte, aprenderás que los errores no son el enemigo. Son, de hecho, la principal herramienta de comunicación que tiene Python para ayudarte a mejorar tu código. Aprenderás a entenderlos, anticiparlos y manejarlos con elegancia.
1. Qué es un error en programación
El error como parte del desarrollo
Equivocarse forma parte normal del desarrollo de software. Ningún programador escribe código perfecto al primer intento. Los mensajes de error de Python no son "castigos", sino diagnósticos detallados que contienen información sumamente útil para decirte exactamente qué salió mal y dónde.
2. Errores de sintaxis
Qué son y ejemplos
Los errores de sintaxis (SyntaxError) ocurren antes de que el programa siquiera empiece a correr. Significan que has escrito algo que viola las reglas gramaticales de Python. El intérprete ni siquiera puede entender la orden.
Ejemplos comunes que causan SyntaxError:
Olvidar los dos puntos : al final de un if, for o def.
Abrir un paréntesis y olvidar cerrarlo: print("Hola"
Abrir comillas y no cerrarlas: texto = "Mensaje
Escribir palabras reservadas mal: iff edad > 18:
3. Errores durante la ejecución (Excepciones)
El concepto de excepción
A diferencia de la sintaxis, estos errores ocurren cuando el código está gramaticalmente bien escrito, pero al ejecutarse, se encuentra con una situación imposible o prohibida. Python "levanta" (lanza) una excepción y detiene el programa.
Tipos comunes de excepciones
No todos los errores son iguales. Python los clasifica:
NameError: Intentas usar una variable o función que no ha sido definida (ej. error tipográfico en el nombre).
TypeError: Intentas hacer una operación con tipos incompatibles (ej. sumar un número con un string: 5 + "Hola").
ValueError: El tipo es correcto, pero el valor en sí no tiene sentido para la operación (ej. int("Perro")).
ZeroDivisionError: Intentas dividir un número matemáticamente entre cero (10 / 0).
IndexError: Intentas acceder a una posición que no existe en una colección (ej. índice 10 en una lista de 3 elementos).
KeyError: Intentas buscar una clave en un diccionario que no ha sido registrada.
FileNotFoundError: Intentas abrir un archivo para lectura, pero la ruta es incorrecta o no existe.
4. Errores lógicos
Qué son y por qué son peligrosos
Un programa puede ejecutarse perfectamente de principio a fin, sin lanzar ninguna excepción, y aun así producir un resultado completamente incorrecto. Estos son errores lógicos o "bugs".
Ejemplo
CÓDIGO:
precio = 100
descuento = 20
total = precio - descuento / 100
print("El total es:", total)
Explicación
El código no genera TypeError ni SyntaxError, pero calcula 99.8 en vez de 80.0. Primero divide 20 / 100 y resta 0.2 a 100. Corrección: total = precio * (1 - descuento / 100). Así, 20 / 100 = 0.2; 1 - 0.2 = 0.8; 100 * 0.8 = 80.0. La fórmula (precio - descuento) / 100 también sería incorrecta: produciría 0.8.
5. Leer un traceback
Anatomía del mensaje de error
Cuando ocurre una excepción, Python imprime un "Traceback" (Rastreo). Aunque parezca intimidante, se lee muy fácilmente si lo observas de abajo hacia arriba:
Tipo de excepción y mensaje: La última línea te dirá exactamente qué pasó (ej. ValueError: invalid literal for int()).
Archivo y número de línea: Subiendo un poco, verás algo como File "script.py", line 4. Esto te indica la línea problemática.
Línea problemática: Python incluso imprimirá la línea exacta de código donde se atascó.
No te abrumes, ve directo a la última línea y luego busca el número de línea.
6. try y except
Qué es y para qué sirve
Nos permite "intentar" ejecutar un código riesgoso y, si ocurre una excepción, "capturarla" para evitar que el programa se estrelle.
Ejemplo básico
CÓDIGO:
try:
    edad = int(input("Edad: "))
    print("Tienes", edad, "años.")
except ValueError:
    print("Debes escribir un número entero.")
Explicación línea por línea
try:: Inicia el bloque seguro. Python intentará ejecutar lo que está indentado aquí.
    edad = int(input("Edad: ")): Operación riesgosa. Si el usuario escribe "Diez", causará un ValueError.
    print(...): Si lo anterior tuvo éxito, se imprime. Si falló, esta línea se salta completamente.
except ValueError:: Si ocurrió específicamente un ValueError, el programa salta a este bloque.
    print("Debes escribir..."): Mensaje amigable que reemplaza al error rojo en pantalla. El programa no se estrella.
7. Capturar excepciones específicas
¿Por qué especificar el error?
Es fundamental especificar qué error esperas (ej. except ValueError:). Si simplemente escribes except:, capturarás TODO indiscriminadamente. Si tuvieras un error tipográfico en tu código (un NameError), el bloque genérico lo atraparía, imprimiría el mensaje de validación, y ocultaría tu verdadero error de programación.
8. Varios bloques except
Manejar múltiples escenarios
Puedes anticipar diferentes fallas y dar una respuesta adecuada a cada una.
CÓDIGO:
try:
    numero = int(input("Ingresa un divisor: "))
    resultado = 100 / numero
    print("Resultado:", resultado)
except ValueError:
    print("Error: No ingresaste un número válido.")
except ZeroDivisionError:
    print("Error: Matemáticamente no es posible dividir por cero.")
9. else
Ejecución en caso de éxito
La cláusula else dentro del manejo de excepciones se ejecuta únicamente si el bloque try termina correctamente sin que haya ocurrido ninguna excepción.
CÓDIGO:
try:
    numero = int(input("Ingresa cantidad: "))
except ValueError:
    print("Entrada incorrecta.")
else:
    print("¡Dato capturado correctamente!")
    print("Procesando:", numero)
10. finally
Ejecución garantizada
El bloque finally se ejecuta normalmente al abandonar la estructura try, tanto si ocurrió una excepción como si no. Por eso es útil para tareas de limpieza. Existen circunstancias excepcionales en las que el proceso puede terminar antes de que finally llegue a ejecutarse.
CÓDIGO:
try:
    x = 1 / 1
except ZeroDivisionError:
    print("Fallo de división.")
finally:
    print("Este mensaje se imprimirá pase lo que pase.")

Combinación con la PARTE IX

CÓDIGO:
try:
    with open("datos_importantes.txt", "r", encoding="utf-8") as archivo:
        contenido = archivo.read()
        print("Archivo leído con éxito.")
except FileNotFoundError:

12. Conversiones seguras
Asegurando tipos
Siempre que conviertas entradas del usuario con int() o float(), debes envolverlas en un bloque try / except ValueError para evitar que usuarios malintencionados o distraídos colapsen tu sistema.
13. Validación mediante bucles
Volver a preguntar al usuario
Combinamos while True con try/except y break para insistir hasta obtener un dato válido, evitando bucles infinitos.
CÓDIGO:
while True:
    try:
        edad = int(input("Ingresa tu edad en números: "))
        break  # Solo se ejecuta si int() no falló
    except ValueError:
        print("Entrada inválida. Por favor, usa números enteros (ej. 25).")

print(f"Edad registrada: {edad}")
14. Validación frente a manejo de excepciones
Diferencias
No son exactamente lo mismo.
Validación: Es comprobar las condiciones antes de actuar (ej. comprobar con if texto.isdigit(): antes de convertir a entero).
Excepciones: Es intentar la acción directamente y manejar el problema si estalla (ej. try: int(texto)).
En Python es muy común usar excepciones para flujo normal (una filosofía conocida como "Es más fácil pedir perdón que permiso"), pero ambas herramientas son útiles.
15. Introducción a raise
Lanzar tus propios errores
Con raise puedes provocar (lanzar) una excepción a propósito si los datos del usuario rompen tus reglas lógicas.
CÓDIGO:
def registrar_edad(edad):
    if edad < 0:
        raise ValueError("La edad no puede ser negativa.")
    return f"Edad {edad} registrada."

# Si llamas a registrar_edad(-5), el programa estallará con tu mensaje.
16. Evitar except: pass
El peligro del silencio
Hacer esto es una práctica terrible:
CÓDIGO:
try:
    resultado = 10 / 0
except:
    pass
Explicación
except: pass oculta las excepciones producidas durante la ejecución del bloque try, incluso KeyboardInterrupt (Ctrl+C) y SystemExit. No puede ocultar un error de sintaxis del propio archivo que impida ejecutar ese bloque. Sí podría capturar un SyntaxError generado durante una operación como compile(). Captura excepciones específicas y comunica el fallo.
17. Buenas prácticas
Capturar excepciones específicas (ej. except ValueError:).
Mantener pequeño el bloque try: Pon dentro solo la línea riesgosa, no 50 líneas de código.
No utilizar excepciones para ocultar errores intencionalmente.
Mostrar mensajes útiles al usuario para que sepa cómo corregir su error.
Registrar información: Guardar los errores reales en un archivo de log para el administrador.
No revelar información sensible: Si falla una conexión a la base de datos, dile al usuario "Error de servidor", no imprimas información sensible sobre la base de datos a un usuario final.
18. Errores frecuentes
Colocar demasiado código dentro de try, lo que dificulta saber qué falló.
Capturar todo indiscriminadamente con un except: solitario.
Olvidar convertir input() y sorprenderse con un TypeError al sumar.
Confundir validación de datos con excepciones.
Continuar la ejecución asumiendo que los datos están bien, cuando el try falló y dejó una variable vacía.
Usar raise de manera incorrecta o sin un mensaje explicativo.

20. Proyecto de la PARTE X: CALCULADORA ROBUSTA
Instrucciones
Crea un programa de calculadora interactiva que cumpla con los siguientes requisitos:
Define funciones simples para sumar, restar, multiplicar y dividir.
En la función de dividir, no manejes la excepción de cero. Deja que ocurra el error matemático natural.
Crea un bucle infinito interactivo (while True).
Pide la operación (+, -, *, /) o la palabra 'salir'.
Pide dos números al usuario. Utiliza bloques try/except para asegurar que son números (ValueError). Si no lo son, muestra un error amigable y usa continue para volver a preguntar.
Al realizar la división matemática, utiliza try/except ZeroDivisionError para capturar el error y mostrar un mensaje, permitiendo que la calculadora siga encendida en lugar de colapsar.
Solución del Proyecto
CÓDIGO:
# 1. Definición de funciones
def sumar(a, b): return a + b
def restar(a, b): return a - b
def multiplicar(a, b): return a * b
def dividir(a, b): return a / b  # Dejamos que Python genere la excepción

print("=== CALCULADORA ROBUSTA ===")
print("Escribe 'salir' para apagar la calculadora.\n")

# 2. Bucle interactivo
while True:
    operacion = input("Elige operación (+, -, *, /) o 'salir': ").strip()
    
    if operacion.lower() == "salir":
        print("Apagando calculadora...")
        break
        
    if operacion not in ["+", "-", "*", "/"]:
        print("Operación no válida. Intenta de nuevo.\n")
        continue

    # Manejo de ValueError
    try:
        num1 = float(input("Primer número: "))
        num2 = float(input("Segundo número: "))
    except ValueError:
        print("Error: Debes ingresar valores numéricos. Volviendo al menú.\n")
        continue

    # Manejo lógico y matemático
    try:
        if operacion == "+":
            res = sumar(num1, num2)
        elif operacion == "-":
            res = restar(num1, num2)
        elif operacion == "*":
            res = multiplicar(num1, num2)
        elif operacion == "/":
            # Manejo de ZeroDivisionError
            res = dividir(num1, num2)
        
        print(f"El resultado es: {res}\n")
        
    except ZeroDivisionError:
        print("Error fatal prevenido: No se puede dividir entre cero.\n")

PARTE XI — Módulos, paquetes, pip y entornos virtuales

En esta undécima parte, aprenderás a organizar y expandir tus programas. Cuando tu código crece, ya no es práctico tenerlo todo en un solo archivo. Además, aprenderás a utilizar código creado por la comunidad mundial de Python para no tener que reinventar la rueda.
1. Qué es un módulo
Qué es y para qué sirve
Un módulo es, sencillamente, un archivo de Python (con extensión .py) que contiene código (variables, funciones, clases) diseñado para ser reutilizado. 
En lugar de tener un archivo programa_gigante.py con mil líneas de código, puedes separar las funciones matemáticas en calculadora.py y las funciones de texto en textos.py, y luego unirlas en tu programa principal. Esto facilita enormemente la lectura, el mantenimiento y la colaboración.
2. import
Qué es
Es la instrucción fundamental para traer código de un módulo a otro archivo.
Ejemplo y explicación
CÓDIGO:
import math
resultado = math.sqrt(25)
print(resultado)
- import math: Busca el módulo llamado math y lo hace disponible en este archivo.
- math.sqrt(25): Accede a la función sqrt (raíz cuadrada) que "vive" dentro del módulo math. Nota cómo usamos el nombre del módulo seguido de un punto (.) para acceder a su contenido.
- print(resultado): Imprime el resultado, que es 5.0.
3. from ... import ...
Qué es y cómo se compara
A veces no quieres importar todo el módulo, sino solo una función específica.
CÓDIGO:
from math import sqrt
resultado = sqrt(25)
print(resultado)
Diferencia clave: Al usar from ... import ..., ya no necesitas escribir math. antes de la función. La función se importa directamente a tu "espacio de nombres" local.
4. Alias con as
Qué es y para qué sirve
Puedes cambiar el nombre con el que importas un módulo para escribir menos o evitar conflictos de nombres.
CÓDIGO:
import statistics as stats
datos = [10, 20, 30]
promedio = stats.mean(datos)
Cuándo ayuda: Cuando el módulo tiene un nombre muy largo (ej. import matplotlib.pyplot as plt).
Cuándo perjudica: Si inventas alias poco claros (ej. import statistics as s), harás que tu código sea ilegible para otros programadores.
5. Evitar import *
Por qué es una mala práctica
CÓDIGO:
from math import *
Esta sintaxis importa todas las funciones del módulo directamente. Suele evitarse en código profesional por tres razones:
1. Sombreado/Colisiones: Si tú creaste una función llamada pi() y luego haces from math import *, la versión de math sobrescribirá la tuya.
2. Legibilidad: Si alguien más lee tu código y ve la función cos(x), no sabrá si proviene de math, de numpy, o si la escribiste tú.
3. Espacio de nombres: import * añade nombres y dificulta saber su origen. No evita cargar e inicializar el módulo; el problema principal es la claridad y las colisiones, no un supuesto ahorro de memoria.
6. Biblioteca estándar
Qué es
Python viene "con las pilas incluidas". La biblioteca estándar es un conjunto de módulos que ya vienen preinstalados con Python. No necesitas descargarlos, solo importarlos.
Ejemplos comunes:
math: Operaciones matemáticas avanzadas.
random: Generación de números y selecciones aleatorias.
statistics: Funciones estadísticas (media, mediana, etc.).
datetime: Trabajo con fechas y horas.
pathlib: Manejo avanzado de rutas de archivos.
7. Crear nuestro propio módulo
Veamos cómo conectar dos archivos.
Archivo 1: operaciones.py
CÓDIGO:
def sumar(a, b):
    return a + b
def restar(a, b):
    return a - b
Archivo 2: main.py (Debe estar en la misma carpeta)
CÓDIGO:
import operaciones
resultado = operaciones.sumar(4, 5)
print("La suma es:", resultado)
Explicación
Al ejecutar main.py, Python lee import operaciones y busca un archivo llamado operaciones.py en la misma carpeta.
Lo carga en memoria.
operaciones.sumar(4, 5) utiliza la función definida en el otro archivo.
8. if __name__ == "__main__":
Qué es y para qué sirve
Cuando importas un módulo, Python ejecuta todo el código de ese módulo de arriba a abajo. Si operaciones.py tuviera prints o llamadas a funciones sueltas, se ejecutarían al instante de ser importado, lo cual normalmente no deseas.
La variable mágica __name__ contiene el nombre del módulo actual. Sin embargo, cuando ejecutas un archivo directamente (ej. python main.py), Python le asigna a __name__ el valor especial __main__.
El patrón estándar
CÓDIGO:
def iniciar_programa():
    print("El programa ha iniciado.")
if __name__ == "__main__":
    iniciar_programa()
Explicación: Si ejecutas este archivo directamente, la condición es verdadera y arranca el programa. Si otro archivo importa este módulo, __name__ no será __main__ (será el nombre del archivo), la condición será falsa, y el código no se ejecutará automáticamente. Es una protección.
9. Qué es un paquete
Módulo vs Paquete
Módulo: Normalmente un único archivo .py.
Paquete: Una carpeta o estructura de directorios que contiene múltiples módulos (y posiblemente otros sub-paquetes) organizados de forma lógica.
Estructura de ejemplo
CÓDIGO:
mi_paquete/
├── __init__.py
├── calculos.py
└── textos.py
10. __init__.py
Su papel en Python moderno
Históricamente, Python requería que cualquier carpeta que actuara como paquete tuviera un archivo (generalmente vacío) llamado __init__.py. 
En el Python moderno no es estrictamente obligatorio en todos los casos para crear paquetes simples, pero continúa siendo una convención muy común y útil. Se utiliza para inicializar el paquete, importar herramientas específicas automáticamente cuando el paquete es llamado, o señalar claramente que esa carpeta es un paquete de Python.
11. Biblioteca estándar frente a paquete externo
Biblioteca Estándar: (ej. math, random) Vienen instalados con Python. Solo requieres import.
Paquete Externo: (ej. requests, pandas, flask) Son creados por la comunidad. No vienen con Python. Debes descargarlos e instalarlos desde fuentes de distribución (como PyPI) antes de poder usar import.
12. Qué es pip
El gestor de paquetes
pip (Pip Installs Packages) es la herramienta principal utilizada para instalar y gestionar paquetes de software externos escritos en Python.
Ejecución recomendada
Ejecuta pip mediante el intérprete elegido: fuera de un entorno virtual, py -m pip en Windows o python3 -m pip en macOS/Linux. Dentro de un entorno activado, usa python -m pip. Los ejemplos siguientes con python suponen ese entorno activado; nombre_paquete es un marcador, no un paquete real que debas instalar.
CÓDIGO:
python -m pip install nombre_paquete
¿Por qué? Si tienes varias versiones de Python instaladas (ej. Python 3.10 y Python 3.11), python -m pip garantiza que el paquete se instale exactamente para la versión de Python que estás invocando con el comando python.
13. Comandos básicos de pip
CÓDIGO:
# Ver versión de pip
python -m pip --version
# Instalar un paquete
python -m pip install requests
# Instalar una versión específica
python -m pip install requests==2.28.1
# Ver paquetes instalados en tu entorno
python -m pip list
# Ver información de un paquete específico
python -m pip show requests
# Eliminar un paquete
python -m pip uninstall requests
14. Seguridad al instalar paquetes
Buenas prácticas críticas
Comprueba el nombre exacto: Existen atacantes que suben paquetes maliciosos con nombres similares a los populares (ej. requsts en lugar de requests). A esto se le llama "Typosquatting".
Revisa la documentación: Antes de instalar, busca el paquete en pypi.org o lee su documentación oficial.
No instales a ciegas: No ejecutes comandos de instalación de foros o tutoriales dudosos sin entender qué estás instalando.
Aísla tus proyectos: Usa entornos virtuales (ver siguiente punto).
15. Qué es un entorno virtual
El problema
Imagina que construyes el "Proyecto A" hoy usando el paquete externo django en su versión 3.0. Dentro de un año, construyes el "Proyecto B", que requiere django versión 5.0. 
Si instalas paquetes de manera "global" en tu computadora, al actualizar django a la versión 5.0, ¡el Proyecto A dejará de funcionar!
La solución: Aislamiento
venv crea un entorno sobre una instalación base, con paquetes propios y una copia o enlace al ejecutable según el sistema y las opciones. No es una instalación totalmente independiente ni una barrera de seguridad. Permite separar dependencias de proyectos. Fuente: Entornos virtuales con venv
16. Crear un entorno con venv
Creación
Desde la carpeta del proyecto, usa python -m venv .venv en Windows con Python Install Manager o python3 -m venv .venv en macOS/Linux. El ejemplo siguiente corresponde a Windows.
CÓDIGO:
python -m venv .venv
Se crea .venv con su configuración y directorios. El punto inicial suele ocultarla en sistemas Unix, pero no implica que Windows la marque como oculta.
17. Activar el entorno virtual
Comandos por sistema operativo
La activación facilita usar el entorno, pero no es obligatoria. También puedes ejecutar directamente .venv/Scripts/python.exe en Windows o .venv/bin/python en macOS/Linux.
Windows PowerShell:
CÓDIGO:
.\.venv\Scripts\Activate.ps1
Windows CMD:
CÓDIGO:
.venv\Scripts\activate.bat
Linux / macOS:
CÓDIGO:
source .venv/bin/activate
Cuando está activo suele aparecer (.venv). Si PowerShell impide activar el script, puedes usar directamente su python.exe. La documentación ofrece Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser: modifica la política del usuario; úsalo solo si corresponde a tu equipo y sus reglas.
18. Desactivar
Cuando termines de trabajar, para salir del entorno virtual y volver al Python global de tu computadora, simplemente escribe:
CÓDIGO:

22. Conflictos de nombres (Sombreado)
El riesgo de nombrar mal tus archivos
Evita llamar random.py a un archivo situado junto a tu script si este usa import random: puede ocultar el módulo estándar. No ocurre igual en todos los módulos ni modos de ejecución.

Al ejecutar un script, su carpeta suele encabezar sys.path; con -c o en modo interactivo suele ser el directorio actual. Puedes inspeccionarlo con import sys; print(sys.path). PARTE XII — Programación Orientada a Objetos

En esta duodécima parte, daremos el salto más importante en tu forma de pensar sobre el código. Hasta ahora, hemos usado programación estructurada (variables y funciones sueltas). La Programación Orientada a Objetos (POO) te permite agrupar datos y funciones relacionadas en una sola entidad lógica.
1. Qué es la Programación Orientada a Objetos
Qué es y qué problema resuelve
La POO es un "paradigma" (una forma de pensar y estructurar el código). A medida que un programa crece, tener cientos de variables y docenas de funciones sueltas se vuelve inmanejable. 
La POO resuelve este problema de organización agrupando los datos y el comportamiento que les corresponde dentro de "paquetes" independientes llamados objetos.
Objetos: Representan entidades del mundo real o del sistema (ej. Usuario, Factura, Enemigo, Botón).
Datos (Atributos): Lo que el objeto es o tiene (ej. nombre, saldo, color).
Comportamiento (Métodos): Lo que el objeto puede hacer (ej. saludar, pagar, atacar, hacer_click).
2. Qué es una clase
Qué es
Una clase define el comportamiento y los atributos de sus instancias. La analogía del molde ayuda, pero en Python la clase también es un objeto: al ejecutar class se crea un objeto clase. Persona no es una instancia ordinaria de Persona; ana = Persona(...) crea una instancia.
Sintaxis
CÓDIGO:
class Persona:
    pass
class: Palabra reservada para definir una clase.
Persona: Nombre de la clase. Por convención, se usa PascalCase (CadaPalabraConMayúscula).
pass: Indica que la clase está vacía por ahora.
3. Objeto e instancia
Qué son
Un "objeto" (o "instancia") es el resultado concreto de construir algo usando el plano (la clase). Si Persona es el concepto general, tú y yo somos instancias concretas de esa clase.
Ejemplo
CÓDIGO:
persona1 = Persona()
persona2 = Persona()
Persona() (con paréntesis) le dice a Python: "Construye un nuevo objeto usando el molde Persona".
persona1 y persona2 son dos instancias distintas en la memoria de la computadora.
4. El método __init__
Qué es y para qué sirve
Es un "método mágico" especial (nota el doble guion bajo a cada lado). Se ejecuta automáticamente en el instante en que creas un nuevo objeto. Sirve para inicializar (dar valores iniciales a) los atributos de esa instancia específica.
Ejemplo paso a paso
CÓDIGO:
class Persona:
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad

juan = Persona("Juan", 30)
Explicación
def __init__(self, nombre, edad):: Define el método inicializador que recibe datos.
self.nombre = nombre: Guarda el argumento "Juan" dentro del atributo nombre de esta instancia específica.
juan = Persona("Juan", 30): Crea el objeto y automáticamente envía "Juan" y 30 a __init__.
5. La palabra clave self
Qué es
self representa a la instancia concreta sobre la que se está trabajando.
Cuando tienes cientos de objetos Persona, el código de la clase es el mismo para todos. Python usa self para saber a qué objeto específico le estás hablando. Siempre debe ser el primer parámetro de cualquier método de instancia, aunque al llamar al método nunca lo escribes (Python lo envía automáticamente).
6. Atributos
Qué son y cómo usarlos
Son las variables que viven dentro del objeto.
CÓDIGO:
# Acceder a un atributo
print(juan.nombre)

# Modificar un atributo
juan.edad = 31
print(juan.edad)
7. Métodos
Qué son
Son las funciones que viven dentro del objeto y definen su comportamiento.
CÓDIGO:
class Persona:
    def __init__(self, nombre):
        self.nombre = nombre

    def saludar(self):
        print(f"Hola, soy {self.nombre}")

ana = Persona("Ana")
ana.saludar() # Imprime: Hola, soy Ana
Atributo = Dato (ana.nombre)
Método = Acción (ana.saludar())
8. Estado de un objeto
Qué es
El "estado" es el conjunto de valores actuales de todos los atributos de un objeto en un momento dado. Los métodos son la forma correcta de modificar ese estado.
CÓDIGO:
class Cuenta:
    def __init__(self, titular, saldo_inicial):
        self.titular = titular
        self.saldo = saldo_inicial
    
    def depositar(self, cantidad):
        self.saldo += cantidad
        print(f"Depositaste {cantidad}. Saldo nuevo: {self.saldo}")

mi_cuenta = Cuenta("Carlos", 100)
mi_cuenta.depositar(50) # Modifica el estado interno
9. Atributos de instancia
Como vimos, si declaras self.nombre = nombre dentro de __init__, ese atributo le pertenece exclusivamente a esa instancia. Si juan.nombre = "Juan" y ana.nombre = "Ana", no interfieren entre sí.
10. Atributos de clase
Si declaras una variable directamente dentro de la clase (fuera de __init__ y sin self.), pertenece a la clase entera y es compartida por todas las instancias.
CÓDIGO:
class Persona:
    especie = "Humano" # Atributo de clase
    
    def __init__(self, nombre):
        self.nombre = nombre # Atributo de instancia

print(Persona.especie)
11. ADVERTENCIA IMPORTANTE — ATRIBUTOS MUTABLES DE CLASE
Debes tener extremo cuidado al usar tipos mutables (como listas o diccionarios) como atributos de clase.
CÓDIGO PROBLEMÁTICO:
class Perro:
    trucos = [] # Atributo mutable de clase (¡Peligro!)

    def agregar_truco(self, truco):
        self.trucos.append(truco)

fido = Perro()
rex = Perro()
fido.agregar_truco("Dar la pata")
print(rex.trucos) # Imprimirá ['Dar la pata'] ¡Aunque Rex no lo aprendió!
Por qué ocurre
Al ser un atributo de clase, existe una única lista compartida por todas las instancias de Perro. Si Fido modifica esa lista, Rex también se ve afectado.
La solución
Si quieres que cada perro tenga sus propios trucos independientes, la lista debe ser un atributo de instancia:
CÓDIGO CORRECTO:
class Perro:
    def __init__(self):
        self.trucos = [] # Cada instancia tiene su propia lista independiente
        
    def agregar_truco(self, truco):
        self.trucos.append(truco)
(Nota: Los atributos mutables de clase no están prohibidos. Son muy útiles cuando realmente quieres un estado compartido intencional, como una lista general que lleve el registro de todos los usuarios creados).
12. El método __str__
Qué es
Si intentas hacer print(juan), Python imprimirá algo feo como <__main__.Persona object at 0x7f...>, porque no sabe cómo convertir tu objeto complejo en texto. __str__ define exactamente qué string debe devolverse cuando alguien intente imprimir el objeto.
CÓDIGO:
class Libro:
    def __init__(self, titulo, autor):
        self.titulo = titulo
        self.autor = autor
        
    def __str__(self):
        return f"'{self.titulo}' escrito por {self.autor}"

mi_libro = Libro("1984", "George Orwell")
print(mi_libro) # Imprime: '1984' escrito por George Orwell
13. Encapsulación introductoria
La convención del guion bajo
A veces un objeto tiene atributos internos que no deberían ser modificados directamente desde fuera porque podrían romper su lógica. Python no tiene privacidad estricta (no te bloquea), pero confía en una convención: si un atributo empieza con un guion bajo _, le estás diciendo a otros programadores: "Esto es de uso interno, por favor no lo modifiques directamente".
CÓDIGO:
class Sistema:
    def __init__(self):
        self._estado_interno = "Cargando" # Convención de uso interno
14. Herencia
Qué es
Permite crear una nueva clase (clase hija) que toma (hereda) todos los atributos y métodos de una clase existente (clase padre), permitiéndote reutilizar código y especializar objetos.
CÓDIGO:
class Animal:
    def hablar(self):
        print("Sonido genérico")

class Perro(Animal):
    pass

mi_perro = Perro()
mi_perro.hablar() # Imprime: Sonido genérico (heredado de Animal)
15. Sobrescritura de métodos
Si la clase hija necesita hacer algo diferente a la clase padre, simplemente defines un método con el mismo nombre y lo "sobrescribes".
CÓDIGO:
class Perro(Animal):
    def hablar(self):
        return "¡Guau!"

mi_perro = Perro()
print(mi_perro.hablar()) # Imprime: ¡Guau!
16. super()
Qué es y para qué sirve
A veces no quieres sobrescribir un método completamente perdiendo todo el código original; quieres aprovechar el código del padre y agregarle más cosas. super() llama temporalmente al método de la clase padre. Es muy usado en __init__.
CÓDIGO:
class Persona:
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad

class Empleado(Persona):
    def __init__(self, nombre, edad, puesto):
        # 1. Dejamos que la clase Persona maneje nombre y edad
        super().__init__(nombre, edad) 
        # 2. Manejamos lo nuevo (puesto)
        self.puesto = puesto
17. Polimorfismo
Qué es
Significa "muchas formas". En la práctica, significa que puedes usar un método con el mismo nombre en objetos de diferentes clases, y cada uno responderá a su manera, sin que el programa principal deba preocuparse de qué clase exacta es cada objeto.
CÓDIGO:
class Gato:
    def hablar(self): return "Miau"

class Vaca:
    def hablar(self): return "Muu"

# No importa de qué clase sea el animal, sabemos que tiene un método hablar()
animales = [Gato(), Vaca(), Perro()]
for animal in animales:
    print(animal.hablar())
18. Composición
Qué es
Otra forma de construir objetos. En lugar de decir "Un Perro es un Animal" (Herencia), decimos "Un Auto tiene un Motor" (Composición). Consiste en que un objeto guarda a otro objeto dentro de sus atributos.
CÓDIGO:
class Motor:
    def encender(self):
        print("Motor encendido")

class Auto:
    def __init__(self):
        self.motor = Motor() # Auto contiene un Motor
        
    def arrancar(self):
        self.motor.encender()
19. Herencia frente a Composición
Herencia (Es un): Usa esto cuando una clase claramente es una versión especializada de otra (ej. un Empleado es una Persona).
Composición (Tiene un): Usa esto cuando una clase está compuesta de otras piezas, o utiliza a otras (ej. un Estudiante tiene una Mochila). No abuses de la herencia; la composición suele crear código más flexible.
20. Cuándo usar clases
No todo programa de Python requiere programación orientada a objetos. Un script de 20 líneas para leer un archivo y sumar sus números puede vivir perfectamente con variables y funciones.
Usa clases cuando notes que tienes:
Grupos de datos y funciones que siempre viajan juntos.
Necesidad de crear múltiples "instancias" de algo (múltiples enemigos, usuarios, conexiones).
Necesidad de recordar el estado interno de algo a lo largo del tiempo.
21. Errores frecuentes
ERROR FRECUENTE: En un método de instancia, el primer parámetro recibe la instancia; por convención se llama self, pero no es una palabra reservada. Omitirlo puede producir TypeError al llamar al método. Escribir nombre en lugar de self.nombre puede causar NameError si nombre no está definido.
ATRIBUTOS: Persona.nombre = "Ana" es válido y asigna un atributo a la clase. ana.nombre = "Ana" asigna un atributo a esa instancia. No son equivalentes; crea primero la instancia con los argumentos que exija su __init__.
ERROR FRECUENTE: mi_perro.hablar obtiene el método enlazado, pero no lo ejecuta. Para llamarlo escribe mi_perro.hablar(); si devuelve un texto, usa print(mi_perro.hablar()) para mostrarlo.
ERROR FRECUENTE: Crear listas como atributos de clase pensando que serán atributos de instancia (el problema de Fido y Rex).
ERROR FRECUENTE: Abusar de la herencia creando jerarquías de 5 niveles de profundidad que nadie puede entender.
ERROR FRECUENTE: Olvidar llamar a super().__init__() en una clase hija, provocando que los atributos de la clase padre nunca se creen.

Instrucciones

2. Crea un método prestar() en Libro que, si está disponible, lo marque como False y avise del éxito. Si no, avise que ya está prestado.
3. Crea una clase Biblioteca (Composición). Debe tener un atributo catalogo (una lista vacía).
4. Agrega a Biblioteca un método agregar_libro(libro) que reciba un objeto Libro y lo añada a la lista.

Solución del Proyecto
CÓDIGO:
class Libro:
    def __init__(self, titulo, autor):
        self.titulo = titulo
        self.autor = autor
        self.disponible = True
        
    def prestar(self):
        if self.disponible:
            self.disponible = False
            print(f"Éxito: Se ha prestado '{self.titulo}'.")
        else:
            print(f"Error: '{self.titulo}' ya está prestado.")
            
    def __str__(self):
        estado = "Disponible" if self.disponible else "Prestado"
        return f"'{self.titulo}' de {self.autor} ({estado})"

class Biblioteca:
    def __init__(self):
        self.catalogo = []
        
    def agregar_libro(self, libro):
        self.catalogo.append(libro)
        print(f"Libro '{libro.titulo}' agregado a la biblioteca.")
        
    def mostrar_disponibles(self):
        print("\n--- LIBROS DISPONIBLES ---")
        for libro in self.catalogo:
            if libro.disponible:
                print(libro)

Solución: Falla con un TypeError: encender() takes 0 positional arguments but 1 was given. El método encender no tiene el parámetro self definido, pero Python siempre envía la instancia (pc) como primer argumento oculto al llamarlo. Debe ser def encender(self):.
Predicción de salida
¿Qué imprime el siguiente código?
CÓDIGO:
class Auto:
    ruedas = 4

auto1 = Auto()
auto2 = Auto()
Auto.ruedas = 6

print(auto1.ruedas)
Solución: Imprimirá 6. Como ruedas es un atributo de clase, al cambiarlo a través de la clase (Auto.ruedas = 6), todas las instancias que leen ese atributo reflejarán el nuevo valor compartido.
PARTE XIII — Python Intermedio

En esta decimotercera parte, aprenderás herramientas que separan a los principiantes de los programadores de nivel intermedio. Estas herramientas no añaden necesariamente nuevas capacidades a lo que ya puedes hacer, pero te permitirán escribir código mucho más elegante, conciso, rápido y "pitónico".
1. List comprehensions (Comprensiones de listas)
Las comprehensions son una forma concisa y elegante de crear listas nuevas basadas en colecciones existentes en una sola línea.
La forma tradicional
Si quieres crear una lista con los cuadrados de los números del 1 al 5, normalmente escribirías esto:
CÓDIGO:
cuadrados = []
for numero in range(1, 6):
    cuadrados.append(numero ** 2)
print(cuadrados) # [1, 4, 9, 16, 25]
La forma usando Comprehension
Podemos lograr exactamente lo mismo con esta sintaxis:
CÓDIGO:
cuadrados = [numero ** 2 for numero in range(1, 6)]
print(cuadrados) # [1, 4, 9, 16, 25]
Explicación de los componentes
Una comprensión se lee de izquierda a derecha, pero la lógica fluye así:
for numero in range(1, 6): De dónde sacamos los datos (el bucle).
numero ** 2: Qué le hacemos a cada dato (la expresión o transformación).
[...]: Guarda todos los resultados en una nueva lista.
Comprehensions con condición
También puedes incluir un condicional if para filtrar datos mientras se crea la lista.
CÓDIGO:
# Obtener solo los números pares del 0 al 9
pares = [n for n in range(10) if n % 2 == 0]
print(pares) # [0, 2, 4, 6, 8]
Buena Práctica: Las comprehensions son excelentes, pero no abuses de ellas. Si tu comprensión ocupa más de dos líneas o tiene condicionales anidados complejos, vuelve a usar un bucle for tradicional. El objetivo principal es la legibilidad.
2. Dictionary comprehensions
Puedes aplicar el mismo concepto para crear diccionarios. Observa cómo usamos {} y los dos puntos :.
CÓDIGO:
# Crear un diccionario donde la clave es el número y el valor es su cuadrado
cuadrados_dict = {n: n ** 2 for n in range(1, 6)}
print(cuadrados_dict) # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
3. Set comprehensions
Igual que los diccionarios, pero solo con valores. Resulta muy útil porque un set elimina los duplicados de forma natural.
CÓDIGO:
# Aunque haya muchos números, el conjunto solo guardará valores únicos
restos = {n % 3 for n in range(10)}
print(restos) # {0, 1, 2}
4. Unpacking (Desempaquetado)
El desempaquetado permite asignar los elementos de una colección a variables individuales de forma directa y elegante.
Desempaquetado básico
CÓDIGO:
# En lugar de:
# datos = ["Ana", 20]
# nombre = datos[0]
# edad = datos[1]

# Hacemos esto:
nombre, edad = ["Ana", 20]
print(nombre) # Ana
Intercambio de variables
En otros lenguajes necesitas una variable temporal. En Python el desempaquetado lo hace directamente:
CÓDIGO:
a = 10
b = 20
a, b = b, a # Ahora a es 20 y b es 10
Desempaquetado avanzado con asterisco (*)
Puedes atrapar "el resto" de los elementos en una lista usando *.
CÓDIGO:
primero, *resto = [1, 2, 3, 4]
print(primero) # 1
print(resto)   # [2, 3, 4]
5. enumerate()
Cuando recorres una lista, muchas veces necesitas conocer tanto el elemento como su índice (posición).
La forma antigua (poco elegante)
CÓDIGO:
nombres = ["Ana", "Luis", "Carlos"]
for indice in range(len(nombres)):
    print(indice, nombres[indice])
La forma moderna y clara con enumerate
enumerate devuelve automáticamente pares de (índice, elemento).
CÓDIGO:
for indice, nombre in enumerate(nombres):
    print(f"Posición {indice}: {nombre}")
6. zip()
zip te permite recorrer múltiples colecciones en paralelo como si fueran un cierre o cremallera.
CÓDIGO:
nombres = ["Ana", "Luis"]
edades = [20, 25]

for nombre, edad in zip(nombres, edades):
    print(nombre, "tiene", edad, "años")
Nota: Si los iterables tienen longitudes diferentes, zip se detendrá automáticamente cuando se agote el más corto. Los elementos restantes del iterable más largo se ignorarán.
7. sorted() frente a .sort()
Este es un error extremadamente común.
.sort()
Es un método de las listas. Modifica la lista original (la ordena in-place) y devuelve None.
CÓDIGO:
lista = [3, 1, 2]
resultado = lista.sort() # Modifica la lista
print(lista)     # [1, 2, 3]
print(resultado) # None (¡No intentes guardar el resultado de .sort()!)
sorted()
Es una función incorporada. NO modifica la colección original, sino que devuelve una nueva lista ordenada. Funciona no solo con listas, sino con cualquier iterable (tuplas, strings).
CÓDIGO:
lista = [3, 1, 2]
nueva_lista = sorted(lista)
print(lista)       # [3, 1, 2] (Intacta)
print(nueva_lista) # [1, 2, 3] (Ordenada)
8. min(), max() y sum()
Funciones incorporadas muy útiles para trabajar con colecciones numéricas rápidamente.
CÓDIGO:
notas = [8.5, 9.0, 7.5, 10.0]
print(min(notas)) # 7.5
print(max(notas)) # 10.0
print(sum(notas)) # 35.0
9. any() y all()
Reciben una colección de booleanos (o expresiones) y evalúan:
all(): Devuelve True solo si TODOS son verdaderos.
any(): Devuelve True si AL MENOS UNO es verdadero.
CÓDIGO:
resultados = [True, True, False, True]
print(all(resultados)) # False (hay un False)
print(any(resultados)) # True (hay varios True)
10. Funciones lambda
Las funciones lambda son funciones "anónimas" (sin nombre) y pequeñas que se escriben en una sola línea. No se usan con def ni tienen la palabra return explícita (el retorno es automático).
CÓDIGO:
# Función normal
def doble_normal(x):
    return x * 2

# Función lambda
doble = lambda x: x * 2

print(doble(5)) # Imprime 10
Aclaración importante: Las lambdas NO reemplazan a def. De hecho, si necesitas asignarle un nombre a la función (como hicimos arriba doble = lambda...), es mucho mejor usar def. Las lambdas brillan cuando necesitas pasar una función matemática rápida como argumento a otra función, sin tomarte la molestia de definirla formalmente en otra parte.
11. map()
map toma una función y una colección, y le aplica esa función a cada elemento de la colección uno por uno. Resulta muy útil si la combinas con una función lambda.
CÓDIGO:
numeros = [1, 2, 3, 4]
# Aplicamos la lambda a cada número de la lista
dobles = list(map(lambda n: n * 2, numeros))
print(dobles) # [2, 4, 6, 8]
(Nota: En Python 3, map no devuelve una lista directamente, sino un "objeto map", por lo que a menudo lo envolvemos en list() para ver los resultados de golpe).
12. Comparación OBLIGATORIA: map() frente a comprehension
En el punto 1 y 11 hicimos exactamente lo mismo. ¿Cuál deberías usar?
Usando map con lambda
CÓDIGO:
dobles = list(map(lambda n: n * 2, numeros))
Usando List Comprehension
CÓDIGO:
dobles = [n * 2 for n in numeros]
¿Cuál es mejor?
Ambas son completamente válidas. No existe una regla universal.
1. Comprehension: Suele ser más legible para la mayoría de los programadores de Python, especialmente cuando la transformación matemática es simple y única.
2. map(): Resulta muy natural y limpio si ya tienes definida una función que hace el trabajo. Por ejemplo, textos_limpios = list(map(limpiar_texto, textos_sucios)) suele leerse mejor que una comprensión.
La elección depende de la claridad en tu contexto específico y de las convenciones de tu equipo de trabajo.
13. filter()
Es el hermano de map. Evalúa una función sobre una colección, pero en lugar de transformar el dato, solo deja pasar aquellos elementos donde la función devuelva True.
CÓDIGO:
numeros = [1, 2, 3, 4, 5, 6]
pares = list(filter(lambda n: n % 2 == 0, numeros))
print(pares) # [2, 4, 6]
También puedes hacer esto con comprensiones: pares = [n for n in numeros if n % 2 == 0]. La elección sigue los mismos principios explicados en el punto anterior.
14. Iterable
Un "iterable" es simplemente cualquier objeto en Python capaz de devolver sus miembros uno a la vez. Dicho de forma simple, es cualquier cosa que puedas recorrer con un bucle for.
Listas [1, 2]
Tuplas (1, 2)
Strings "Hola"
Diccionarios {"a": 1}
Todos ellos son iterables.
15. Iterador
Un iterable permite obtener un iterador con iter(). Un iterador entrega elementos con next() y se agota con StopIteration. Una lista es iterable, pero no es por sí misma un iterador. El bucle for obtiene un iterador y solicita elementos hasta que este se agota.
CÓDIGO:
numeros = [10, 20, 30]
# Obtenemos un iterador del iterable; la lista no se transforma
iterador = iter(numeros)

print(next(iterador)) # 10
print(next(iterador)) # 20
Si intentas hacer next() cuando ya no quedan elementos, Python lanzará una excepción especial llamada StopIteration (esto es exactamente lo que el bucle for detecta internamente para saber cuándo detenerse).
16. Generadores
Los generadores son funciones especiales que, en lugar de devolver todos sus datos de golpe y cerrar, pausan su ejecución, devuelven un solo valor, y recuerdan exactamente dónde se quedaron.
Se construyen usando la palabra yield en lugar de return.
CÓDIGO:
def contar():
    yield 1
    yield 2
    yield 3

# Llamar a la función no la ejecuta, sino que crea un generador
generador = contar()

print(next(generador)) # Imprime 1 y se pausa
print(next(generador)) # Despierta, imprime 2 y se pausa
Diferencia clave: return vs yield
return: Termina la llamada actual y devuelve un valor; no destruye la definición de la función.
yield: Devuelve un valor, pero "congela" la función para continuar después desde ese mismo punto.
17. Expresiones generadoras
Se escriben exactamente igual que una list comprehension, pero usando paréntesis () en lugar de corchetes [].
CÓDIGO:
cuadrados_generador = (n ** 2 for n in range(10))
Diferencia conceptual: Una list comprehension calcula los 10 resultados de golpe y los guarda en la memoria. Una expresión generadora crea un objeto que sabe cómo calcularlos y solo lo hará uno por uno a medida que se lo pidas en un bucle for. Ahorran muchísima memoria en colecciones gigantes.
18. *args
A veces no sabes cuántos argumentos enviará el usuario a tu función. *args le dice a Python que empaquete todos los argumentos posicionales adicionales en una Tupla.
CÓDIGO:
def sumar(*numeros):
    print(type(numeros)) # Imprime <class 'tuple'>
    return sum(numeros)

print(sumar(1, 2))       # 3
print(sumar(1, 2, 3, 4)) # 10
Aclaración: La palabra args es solo una convención comunitaria. Lo verdaderamente importante es el asterisco *. Podrías llamarlo *datos.
19. **kwargs
**kwargs (Keyword Arguments) es similar, pero empaqueta argumentos que fueron pasados con un nombre explícito, y los convierte internamente en un Diccionario.
CÓDIGO:
def mostrar_datos(**datos):
    print(type(datos)) # Imprime <class 'dict'>
    for clave, valor in datos.items():
        print(clave, ":", valor)

mostrar_datos(nombre="Ana", edad=20, rol="Admin")
Aclaración: Igual que antes, kwargs es solo una fuerte convención. El doble asterisco ** es lo que activa el empaquetado de diccionario.
20. Desempaquetado al llamar funciones
Puedes hacer el proceso inverso. Si tienes una función que pide múltiples argumentos y tú tienes esos datos guardados en una colección, puedes usar * o ** en la llamada a la función para desempaquetarlos automáticamente.
CÓDIGO:
def restar(a, b):
    return a - b

numeros = [10, 4]
# *numeros extrae el 10 y el 4 de la lista antes de llamar a la función
resultado = restar(*numeros) 
print(resultado) # 6

# Desempaquetando un diccionario
datos_dict = {"a": 20, "b": 5}
resultado_dict = restar(**datos_dict)
21. Funciones como objetos
En Python, todo es un objeto, incluidas las funciones. Esto significa que puedes guardar una función completa dentro de una variable y pasarla de un lugar a otro.
CÓDIGO:
def saludar():
    return "Hola a todos"

# Guardamos la función en sí, nota que NO usamos paréntesis
mi_funcion = saludar 

# Ahora la variable actúa como la función
print(mi_funcion())
22. Introducción a LEGB
El ámbito (Scope) determina qué variables puede "ver" Python en cada momento. Python resuelve la búsqueda de variables en este orden estricto (LEGB):
1. L (Local): Variables creadas dentro de la función actual.
2. E (Enclosing): Nombres en ámbitos de funciones envolventes, cuando hay funciones anidadas.
3. G (Global): Nombres del módulo donde se define la función.
4. B (Built-in): Nombres incorporados, como las funciones print y len; no son palabras reservadas.
23. nonlocal
Normalmente, una función anidada (una función definida dentro de otra) puede leer las variables de su función envolvente, pero no modificarlas. nonlocal soluciona esto.
CÓDIGO:
def exterior():
    mensaje = "Hola"
    
    def interior():
        nonlocal mensaje # Le dice a Python: "Voy a modificar la variable de arriba"
        mensaje = "Adiós"
        
    interior()
    print(mensaje)

exterior() # Imprimirá "Adiós" en lugar de "Hola"
24. Docstrings
Son strings multilínea """ que se colocan inmediatamente debajo de la definición de una función o clase para documentar oficial y formalmente qué hace.
No es un simple comentario #. Las herramientas profesionales y los editores (IDE) los leen automáticamente para mostrarte ayuda.
CÓDIGO:
def sumar(a, b):
    """
    Suma dos números y devuelve el resultado.
    Parámetros:
    a (int, float): El primer número.
    b (int, float): El segundo número.
    """
    return a + b
25. Type hints (Anotaciones de tipo)
Python es de tipado dinámico, pero desde la versión 3.5 permite "insinuar" (hint) qué tipo de datos espera una función y qué devolverá.
CÓDIGO:
def multiplicar(a: int, b: int) -> int:
    return a * b
ADVERTENCIA FUNDAMENTAL: las anotaciones de tipo no obligan por sí mismas al intérprete de Python a rechazar otros tipos. Si llamas a multiplicar("Hola", 2), Python intentará ejecutar la operación. Los type hints sirven como metadatos para documentación, editores y analizadores estáticos como mypy, y ayudan a detectar incompatibilidades antes de ejecutar el programa.
26. Operador ternario
Es una forma condensada de escribir un simple bloque if / else en una sola línea.
CÓDIGO:
edad = 20
# ValorVerdadero if Condicion else ValorFalso
estado = "adulto" if edad >= 18 else "menor"
Recomendación: Úsalo solo cuando la lógica sea tan breve que mantenga la claridad. Para decisiones complejas, vuelve al if/else tradicional.
27. is frente a ==
== (Igualdad): Compara si los valores guardados dentro de dos objetos son iguales.
is (Identidad): Compara si dos referencias apuntan exactamente al mismo objeto físico en la memoria del ordenador.
CÓDIGO:
lista_a = [1, 2]
lista_b = [1, 2]

print(lista_a == lista_b) # True (Sus valores son los mismos)
print(lista_a is lista_b) # False (Son dos listas diferentes en memoria)
El uso más habitual y correcto de is en Python es para comparar contra el objeto único None.
CÓDIGO:
if resultado is None:
    print("No hay resultado")
28. Referencias y copias
En Python, asignar listas no crea copias automáticas, sino nuevas "etiquetas" apuntando al mismo objeto.
CÓDIGO:
a = [1, 2, 3]
b = a        # Ambos apuntan a la misma lista
b[0] = 99
print(a)     # Imprimirá [99, 2, 3] porque 'a' y 'b' son lo mismo.
Para solucionar esto, necesitas hacer una copia superficial (shallow copy).
CÓDIGO:
a = [1, 2, 3]
b = a.copy() # Ahora b es una lista nueva
b[0] = 99
print(a)     # [1, 2, 3] (Intacta)
29. Errores frecuentes
Comprehension inmanejable: Crear una línea de 150 caracteres con 3 bucles anidados en lugar de código claro.
Creer que .sort() devuelve la lista: Escribir mis_datos = datos.sort() dejará mis_datos con valor None.
Confundir is con ==: Usar if nombre is "Ana":. Funciona a veces por coincidencias del intérprete, pero provocará fallos misteriosos. Usa siempre == para valores.
Consumir un iterador: Un iterador o generador se "agota" tras ser recorrido. Si intentas recorrerlo por segunda vez, estará vacío.
Confundir return y yield: Creer que yield finalizará la función o que un return mantendrá el estado del generador.
Uso innecesario de lambda: Intentar resolver toda la arquitectura de un programa forzando lambdas en lugar de usar def claras y legibles.
Confundir *args y **kwargs: Tratar de atrapar argumentos con nombre x=5 usando *args causará un error.
Creer que los type hints blindan tu código: Confiarse y no validar entradas del usuario asumiendo que Python lanzará un TypeError si envían texto en un argumento int.

31. Proyecto de la PARTE XIII: Analizador de Calificaciones
Instrucciones
Vamos a construir un analizador de rendimiento escolar combinando herramientas intermedias.
1. Define una lista de diccionarios con nombres de estudiantes y sus calificaciones.
2. Usa una función con type hints que reciba esa lista y calcule lo siguiente:
Usa una list comprehension para extraer solo las notas.
Usa min(), max() y sum() sobre la lista extraída para obtener estadísticas.
Usa una list comprehension con condicional para obtener las notas aprobatorias (>= 7).
3. Muestra los resultados de forma ordenada.
4. Usa sorted() o .sort() y enumerate() en otra parte del código para mostrar el listado general en orden de mayor a menor.
Solución del Proyecto
CÓDIGO:
# Base de datos simplificada
estudiantes = [
    {"nombre": "Carlos", "nota": 6.5},
    {"nombre": "Ana", "nota": 9.2},
    {"nombre": "Luis", "nota": 8.0},
    {"nombre": "María", "nota": 7.5}
]

def analizar_rendimiento(datos: list) -> dict:
    """Extrae estadísticas básicas de un grupo de estudiantes."""
    # List comprehension simple
    notas_general = [est["nota"] for est in datos]
    
    # List comprehension con filtro
    aprobados = [nota for nota in notas_general if nota >= 7.0]
    
    # Matemáticas básicas
    maxima = max(notas_general)
    minima = min(notas_general)
    promedio = sum(notas_general) / len(notas_general)
    
    # Retornamos todo organizado en un diccionario
    return {
        "max": maxima,
        "min": minima,
        "prom": promedio,
        "total_aprobados": len(aprobados)
    }

# --- EJECUCIÓN DEL ANÁLISIS ---
print("--- ANÁLISIS ACADÉMICO ---")
estadisticas = analizar_rendimiento(estudiantes)
print(f"Nota Máxima: {estadisticas['max']}")
print(f"Nota Mínima: {estadisticas['min']}")
print(f"Promedio Grupo: {estadisticas['prom']:.2f}")
print(f"Alumnos Aprobados: {estadisticas['total_aprobados']}")

# --- CLASIFICACIÓN USANDO LAMBDA Y SORTED ---
print("\n--- CLASIFICACIÓN ---")
# sorted() devuelve una lista nueva. La lambda le dice que ordene fijándose solo en la "nota"
clasificacion = sorted(estudiantes, key=lambda x: x["nota"], reverse=True)

# enumerate() nos da la posición
for posicion, est in enumerate(clasificacion):
    # Sumamos 1 a posición porque empieza en 0
    print(f"Lugar {posicion + 1}: {est['nombre']} - {est['nota']}")

1. Funciones avanzadas: Anidadas y Closures
Qué son y para qué sirven
Las funciones anidadas son funciones definidas dentro de otras funciones. Un "closure" (cierre) ocurre cuando una función anidada recuerda y tiene acceso a las variables de su función padre, incluso después de que la función padre haya terminado de ejecutarse. Sirven para ocultar lógica interna y para crear "fábricas" de funciones con estado capturado.
CÓDIGO:
def multiplicador(factor):
    def funcion_interna(numero):
        return numero * factor # Captura la variable "factor"
    return funcion_interna

duplicar = multiplicador(2)
print(duplicar(5)) # Imprime 10
Explicación línea por línea
def multiplicador(factor):: Función externa que recibe un argumento.
def funcion_interna(numero):: Función anidada que realiza el trabajo.
return numero * factor: Usa numero (su propio parámetro) y factor (del ámbito superior).
return funcion_interna: La función externa devuelve la función interna en sí misma, sin ejecutarla (sin paréntesis).
duplicar = multiplicador(2): Crea una función que siempre multiplicará por 2.
2. Decoradores
Qué son y para qué sirven
Un decorador es una función que recibe otra función, le añade un comportamiento extra, y devuelve la función modificada. Se usan extensamente en frameworks (como Flask o Django) para verificar permisos, registrar logs o medir tiempos, sin modificar el código original de la función.
Sintaxis y Ejemplo
CÓDIGO:
import functools

def mi_decorador(funcion):
    @functools.wraps(funcion) # Buena práctica: conserva el nombre original de la función
    def envoltura(*args, **kwargs):
        print("Antes de ejecutar la función.")
        resultado = funcion(*args, **kwargs)
        print("Después de ejecutar la función.")
        return resultado
    return envoltura

@mi_decorador
def saludar(nombre):
    print(f"Hola, {nombre}")

saludar("Ana")
Cuándo usarlos
BUENA PRÁCTICA: Usa decoradores cuando tengas lógica transversal que se repite en muchas funciones (ej. verificar si el usuario inició sesión). Evítalos si añaden complejidad innecesaria a un script simple de 10 líneas.
3. POO Avanzada: @property, @classmethod y @staticmethod
Qué son
Son decoradores integrados que modifican el comportamiento de los métodos en las clases.
@property: Permite acceder a un método como si fuera un atributo. Es útil para calcular valores al vuelo o usar "setters" para validar datos antes de guardarlos.
@classmethod: Recibe la clase (cls) como primer argumento, no la instancia. Sirve para crear métodos de fábrica (ej. crear un usuario desde un archivo).
@staticmethod: No recibe ni la instancia ni la clase. Es una función normal que, por organización, se coloca dentro de una clase porque está relacionada con ella.
Ejemplo de @property
CÓDIGO:
class Producto:
    def __init__(self, precio):
        self._precio = precio

    @property
    def precio(self):
        return self._precio

    @precio.setter
    def precio(self, valor):
        if valor < 0:
            raise ValueError("El precio no puede ser negativo")
        self._precio = valor
4. Métodos especiales (Dunder methods)
Qué son
Son métodos con doble guion bajo (Double Under). Permiten que tus objetos interactúen con las funciones integradas de Python (como +, ==, len(), print()).
__init__: Constructor.
__str__: Representación legible para el usuario final (usada por print).
__repr__: Representación técnica exacta para los desarrolladores.
__len__: Permite usar len(objeto).
__eq__: Permite comparar dos objetos con ==.
CÓDIGO:
class Caja:
    def __init__(self, elementos):
        self.elementos = elementos
    def __len__(self):
        return len(self.elementos)
    def __eq__(self, otro):
        return self.elementos == otro.elementos

c1 = Caja([1, 2])
print(len(c1)) # 2

10. Mutabilidad, referencias y copias
Conceptos críticos
Referencia compartida: a = [1, 2]; b = a (Ambos apuntan a la misma lista física).
Copia superficial (Shallow copy): import copy; b = copy.copy(a). Crea una nueva lista externa, pero si hay listas adentro, esas siguen compartidas.
Copia profunda: copy.deepcopy(a) copia recursivamente los componentes que corresponda copiar. Un registro memo conserva relaciones compartidas y evita ciclos; algunas clases personalizan la copia y ciertos objetos no se duplican. No garantiza independencia total para cualquier objeto. Fuente: Copia superficial y profunda

22. Concurrencia, Asyncio y el GIL
Conceptos de múltiples tareas
Concurrencia: Gestionar varias tareas haciendo progresos de forma intercalada (no necesariamente en el mismo milisegundo exacto).
Paralelismo: Ejecutar varias tareas al mismo instante físico (requiere múltiples núcleos en la CPU).
Multiprocessing: Crea procesos separados. Ideal para tareas pesadas de CPU (cálculos matemáticos).
Threading: Usa hilos ligeros.
Asyncio (async/await): La forma moderna de concurrencia para tareas lentas basadas en I/O (descargar archivos, consultas a bases de datos).
async y await
CÓDIGO:
import asyncio

async def tarea():
    print("Iniciando...")
    await asyncio.sleep(1) # Pausa que permite al sistema hacer otras cosas
    print("Terminado.")

# Ejecución en script normal:
# if __name__ == "__main__":
#     asyncio.run(tarea())

# Ejecución en Jupyter Notebooks:
# await tarea()
ACLARACIÓN CRÍTICA: asyncio.run() administra un bucle de eventos para ejecutar un programa asíncrono y no puede llamarse cuando ya existe otro event loop ejecutándose en el mismo hilo. Por eso, en scripts .py suele ser una entrada adecuada, mientras que en entornos interactivos que ya mantienen un event loop —como ocurre habitualmente en Jupyter— puede usarse await a nivel superior cuando el entorno lo admite. No son formas universalmente intercambiables. Para ejecutar varias tareas concurrentes puede utilizarse asyncio.gather() cuando sea apropiado.
El GIL (Global Interpreter Lock)
En las compilaciones tradicionales de CPython, el GIL limita la ejecución simultánea de bytecode de Python por varios hilos. Desde Python 3.13 existen compilaciones de CPython con modo free-threaded, donde el GIL puede estar deshabilitado. Por eso, el efecto del multithreading depende de la versión, la compilación, el tipo de carga y las bibliotecas utilizadas; no debe resumirse como una regla universal de que los hilos nunca aceleran trabajo de CPU.
23. Rendimiento y Big-O
timeit: Módulo para medir microsegundos de ejecución. No promuevas microoptimizaciones prematuras ("Premature optimization is the root of all evil"). Escribe código legible primero.
Big-O: Concepto para razonar cómo se comporta tu código si los datos crecen de 10 a 1 millón. (Buscar en un diccionario es casi inmediato; buscar en una lista gigante es lento).

import time, functools

def tiempo_ejecucion(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        inicio = time.perf_counter()
        res = func(*args, **kwargs)
        fin = time.perf_counter()
        print(f"La función tardó {fin - inicio} seg.")
        return res
    return wrapper

    time.sleep(1)

25. Proyecto de la PARTE XIV: GESTOR MODULAR DE TAREAS
Instrucciones
Crea un sistema que integre Clases Avanzadas, JSON, Type Hints y Logging.
Solución del Proyecto
CÓDIGO:
import json
import logging
from dataclasses import dataclass, asdict
from typing import List

# Configurar Logging
logging.basicConfig(level=logging.INFO, format='%(levelname)s: %(message)s')

@dataclass
class Tarea:
    id: int
    descripcion: str
    completada: bool = False

class GestorTareas:
    def __init__(self, archivo: str):
        self.archivo = archivo
        self.tareas: List[Tarea] = []
        self._cargar()

    def _cargar(self):
        try:
            with open(self.archivo, "r", encoding="utf-8") as f:
                datos = json.load(f)
                self.tareas = [Tarea(**d) for d in datos]
        except FileNotFoundError:
            logging.warning("Archivo no encontrado. Se creará uno nuevo.")

    def guardar(self):
        with open(self.archivo, "w", encoding="utf-8") as f:
            json.dump([asdict(t) for t in self.tareas], f, indent=4, ensure_ascii=False)
        logging.info("Tareas guardadas correctamente.")

    def agregar(self, descripcion: str):
        nueva_id = len(self.tareas) + 1
        self.tareas.append(Tarea(nueva_id, descripcion))
        logging.info(f"Tarea agregada: {descripcion}")
        self.guardar()

if __name__ == "__main__":
    gestor = GestorTareas("mis_tareas.json")
    gestor.agregar("Estudiar Python Avanzado")

Preguntas conceptuales
1. ¿Por qué ensure_ascii=False es útil al hacer json.dump de textos en español?
2. ¿Por qué puede fallar asyncio.run() en un entorno interactivo como Jupyter cuando ya existe un event loop activo en el mismo hilo?
3. ¿Cuál es el riesgo crítico de def funcion(lista=[]):?
Respuestas Rápidas
1. Para evitar que las vocales acentuadas y la ñ se conviertan en caracteres escapados (ej. \u00f1).
2. Porque asyncio.run() no puede ejecutarse cuando ya hay otro event loop activo en el mismo hilo. En entornos interactivos que admiten top-level await, puede usarse await directamente.
3. La lista se inicializa una sola vez. Las llamadas futuras a la función modificarán la misma lista compartida en memoria, causando comportamientos impredecibles.

1. Python en un flujo defensivo y Linux
Python actúa como un puente entre la lógica de monitoreo y el sistema operativo. Permite leer miles de líneas de registros (logs), hacer comprobaciones criptográficas e informar anomalías. Aunque Python funciona en Windows y macOS, en entornos de servidores y defensa cibernética, el conocimiento de integración con Linux es invaluable.
2. Inventario de archivos con pathlib
El primer paso en defensa es saber qué tienes. Usamos pathlib para recorrer nuestras carpetas locales.
Path.iterdir(): recorre únicamente los elementos hijos inmediatos de una carpeta. Al no descender de forma recursiva, normalmente realiza menos trabajo que un recorrido completo; la seguridad depende de la ruta seleccionada y de lo que el programa haga con cada elemento.
Path.rglob("*"): Itera de forma recursiva adentrándose en todas las subcarpetas.
Advertencia de rendimiento: rglob() recorre subdirectorios de forma recursiva, por lo que en árboles grandes puede consumir mucho tiempo y procesar una enorme cantidad de entradas. No debe aplicarse indiscriminadamente sobre la raíz del sistema. En versiones actuales de pathlib, muchos OSError producidos durante el escaneo —incluido PermissionError— se suprimen, pero eso no convierte un recorrido masivo en una buena práctica.
3. Integridad de archivos (SHA-256)
Concepto
Un hash criptográfico funciona como una huella digital del contenido. Un cambio pequeño en el archivo normalmente produce un hash muy diferente. Hashing no es cifrado: no está diseñado para disponer de una operación inversa práctica que recupere el archivo original. En defensa, que dos contenidos tengan el mismo hash aporta una evidencia muy fuerte de igualdad, pero no demuestra por sí solo que el archivo sea seguro o malicioso.
CÓDIGO:
import hashlib
from pathlib import Path

def calcular_sha256(ruta_archivo):
    hash_sha256 = hashlib.sha256()
    with open(ruta_archivo, "rb") as f: # rb = Read Binary
        for bloque in iter(lambda: f.read(4096), b""):
            hash_sha256.update(bloque)
    return hash_sha256.hexdigest()

5. Reglas de detección y Falsos Positivos
Una regla simple podría ser: "Si un usuario falla la contraseña 5 veces en 1 minuto, alertar".
Es fundamental comprender la diferencia: Detección ≠ Confirmación de incidente.

Falso Negativo: Ocurre un ataque real, pero las reglas de Python no lo detectaron. (Peligro).

Un IOC es una pista (una IP sospechosa, un nombre de archivo extraño, un hash malicioso). Buscar un IOC en un sistema requiere contexto. Encontrar el nombre de un archivo sospechoso en una carpeta temporal es una alerta, pero encontrarlo en la documentación del equipo de ciberseguridad es normal.

import json
import re
import logging
from pathlib import Path
from dataclasses import dataclass, asdict
from typing import List

# 1. Configuración Segura y Logging
logging.basicConfig(level=logging.INFO, format='%(levelname)s: %(message)s')
CARPETA_LABORATORIO = Path("./laboratorio_local")
CARPETA_LABORATORIO.mkdir(exist_ok=True)

# Dataset Ficticio para pruebas
log_ficticio = [
    "10:00 - User1 - Login exitoso",
    "10:05 - User2 - Fallo de autenticacion",
    "10:06 - User2 - Fallo de autenticacion"
]

@dataclass
class Alerta:
    tipo: str
    detalles: str

class CentroDefensivo:
    def __init__(self):
        self.alertas: List[Alerta] = []

    def verificar_integridad_laboratorio(self):
        """Calcula el hash de los archivos INMEDIATOS en el laboratorio (No recursivo)."""
        logging.info("Iniciando auditoría de integridad local...")
        for archivo in CARPETA_LABORATORIO.iterdir():
            if archivo.is_file():
                h = hashlib.sha256()
                with open(archivo, "rb") as f:
                    for bloque in iter(lambda: f.read(4096), b""):
                        h.update(bloque)
                logging.info(f"[{archivo.name}] SHA-256: {h.hexdigest()}")

    def analizar_logs_simulados(self):
        """Busca patrones sospechosos en el dataset de logs ficticios."""
        logging.info("Analizando logs...")
        patron_fallo = re.compile(r"Fallo de autenticacion")
        
        for linea in log_ficticio:
            if patron_fallo.search(linea):
                alerta = Alerta("Intento Fallido", linea)
                self.alertas.append(alerta)
                logging.warning(f"Alerta generada: {linea}")

    def exportar_reporte(self):
        """Exporta las alertas correlacionadas a un archivo JSON seguro."""
        ruta_reporte = Path("./reporte_auditoria.json")
        with open(ruta_reporte, "w", encoding="utf-8") as f:
            json.dump([asdict(a) for a in self.alertas], f, indent=4, ensure_ascii=False)
        logging.info(f"Reporte exportado exitosamente a {ruta_reporte}")

if __name__ == "__main__":
    centro = CentroDefensivo()
    
    # Escribir un archivo temporal de prueba en el laboratorio
    archivo_prueba = CARPETA_LABORATORIO / "prueba_integridad.txt"
    archivo_prueba.write_text("Datos confidenciales ficticios", encoding="utf-8")
    
    centro.verificar_integridad_laboratorio()
    centro.analizar_logs_simulados()
    centro.exportar_reporte()
15. Evaluación de la PARTE XV e Integradora
Preguntas conceptuales
1. En un script de auditoría, ¿por qué preferirías iterdir() en lugar de rglob("*") en un directorio grande?
2. Si un archivo .txt y un archivo .exe producen exactamente el mismo hash SHA-256, ¿qué significa desde la perspectiva de la integridad de los datos?
3. ¿Por qué conviene abrir un archivo JSON de texto con una codificación explícita compatible —habitualmente UTF-8— cuando se usa ensure_ascii=False con caracteres no ASCII?
Respuestas Rápidas
1. Porque rglob("*") recorre subdirectorios de forma recursiva y puede visitar muchísimas más entradas que iterdir(). Su coste crece con la cantidad de archivos y carpetas que debe examinar; no es correcto describirlo automáticamente como "exponencial".
2. Significa un evento de "colisión" (extremadamente improbable con SHA-256) o, más comúnmente, que ambos archivos tienen exactamente el mismo contenido binario interno a nivel de bits, a pesar de tener nombres o extensiones diferentes.
3. Con ensure_ascii=False los caracteres no ASCII se escriben literalmente, por lo que el archivo debe abrirse con una codificación capaz de representarlos. UTF-8 es la opción habitual y portable. Si se usa una codificación que no admite algún carácter, puede producirse UnicodeEncodeError; no debe afirmarse que omitir UTF-8 corrompa necesariamente los datos.
