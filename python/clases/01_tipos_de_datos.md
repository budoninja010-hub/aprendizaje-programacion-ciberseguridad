# Clase 01 — Tipos de datos básicos

## Objetivo

Reconocer los cuatro tipos de datos básicos trabajados al inicio del curso.

## Tipos vistos

- `str`: texto.
- `int`: número entero.
- `float`: número con parte decimal.
- `bool`: valor lógico, `True` o `False`.

## Ejemplos

```python
nombre = "Hugo"      # str
edad = 40            # int
peso = 75.5          # float
estudia = True       # bool
```

## Idea clave

Python puede identificar el tipo de un valor con `type()`.

```python
print(type(nombre))
print(type(edad))
print(type(peso))
print(type(estudia))
```
