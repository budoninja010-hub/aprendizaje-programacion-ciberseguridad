# Ejercicios de Python

Prácticas cortas por tema. El número coincide con el de la clase en [`../clases/`](../clases/README.md).

| N.º | Archivo | Tema |
|---|---|---|
| 01 | [01_tipos_de_datos.py](01_tipos_de_datos.py) | `str`, `int`, `float`, `bool` y `type()` |
| 02 | [02_division_division_entera_modulo.py](02_division_division_entera_modulo.py) | `/`, `//`, `%` y par/impar con `% 2` |

## Cómo ejecutar un ejercicio

Desde la raíz del repositorio:

```sh
python3 python/ejercicios/01_tipos_de_datos.py
```

En Windows el comando suele ser `py` o `python` en lugar de `python3`.

Nombre de archivo para nuevos ejercicios: `NN_tema.py`.
