# Progreso de Python

## Temas trabajados

- Tipos de datos básicos: `str`, `int`, `float`, `bool`.
- Operadores aritméticos básicos.
- División normal: `/`.
- División entera: `//`.
- Módulo o residuo: `%`.
- Uso de `% 2` para reconocer números pares e impares.

## Ejercicios ya practicados

- `17 // 5 = 3`
- `20 // 6 = 3`
- `15 // 3 = 5`
- `14 / 4 = 3.5`
- `14 // 4 = 3`
- `14 % 4 = 2`
- `23 / 5 = 4.6`
- `23 // 5 = 4`
- `23 % 5 = 3`

## Corrección registrada

- `19 / 2 = 9.5`.
- `19 // 2 = 9`.
