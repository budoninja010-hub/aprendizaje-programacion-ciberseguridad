# Linux

Apuntes y prácticas de Linux desde cero.

## Organización prevista

- `comandos/`: comandos básicos y ejemplos.
- `bash/`: scripts de Bash creados durante el aprendizaje.
- `laboratorios/`: prácticas realizadas en entornos propios o autorizados.

No se almacenarán contraseñas, claves privadas ni información sensible.
